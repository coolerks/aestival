两种类型都保留项目下的会话列表和固定“聊天”页签。普通项目沿用当前文件、终端、搜索、日志、会话调试与项目看板；笔记项目作为 Markdown 工作区，使用 Vditor 提供源码、并排、即时、预览四种同页签模式，并提供大纲、反向链接、标签与属性、全局/局部知识图谱和多编辑组。笔记右侧栏只允许文件、搜索、大纲、反向链接、标签与属性、局部图谱，底部只允许搜索与反向链接；代码/纯文本只读，图片、PDF、音视频安全预览。图谱由 Cytoscape.js 承载，关系只来自 Markdown 链接与 `[[WikiLink]]`，不生成 AI 推测关系。

聊天模式始终禁止工具。笔记项目的代理模式只允许在已配置根目录内执行受审批的文件操作、搜索和内容/图片素材生成，禁止越界、Shell、构建、调试、文件执行和项目看板动作。详细规格见 [16-项目与笔记工作区](./设计方案/16-项目与笔记工作区.md)。

### 阅读

左侧栏在“应用”正下方增加使用 Lucide `Rss` 的“阅读”，其他菜单相对顺序不变。阅读页默认采用文章列表 + 阅读窗的可调布局，合集选择器并入文章列表，窄窗口在列表与正文之间单页切换；页面名称只显示在全局标题栏。

+ 系统合集只有“精选”和“全部”，不可重命名、删除或重排。
+ “全部”展示所有订阅及保留历史中的文章；“精选”按质量基线和用户口味筛选。
+ 所有合集按发布时间倒序，AI 不改变排序；相似或重复报道逐篇保留。
+ 自定义合集分为订阅源合集和 AI 合集，两类不可互换：前者选择一个或多个 Feed 并包含全部文章，后者不选择来源、按自然语言要求分析所有活跃订阅的新文章。
+ 来源与文章均可进入多个合集；AI 合集创建支持仅新文章、7/30/90 天或全部回溯，默认 30 天并先预览匹配。
+ 支持已读/未读、收藏、批量标记已读、复制链接、打开原文和显式 AI 反馈；收藏只是筛选条件，不增加系统合集。
+ 默认打开方式可设为列表 + 阅读窗、整页阅读或直接打开原网页；已读触发可设为打开时、滚动到底或仅手动。
+ 设置中以“订阅源、合集、AI 与精选、阅读偏好”四个页签完成管理，支持公开 RSS/Atom/JSON Feed 候选预览和 OPML 迁移规格。
+ 阅读 AI 的远程模型首次启用前必须说明发送正文/摘要、元数据和用户要求，不发送 Feed 凭据；只使用显式、可撤销反馈，不暗中学习。
+ 首版只展示 Feed 正文或摘要，不做私有 Feed、网页全文提取、嵌入原网页、播客专项体验或去重聚合。

详细规格见 [15-RSS阅读与智能合集](./设计方案/15-RSS阅读与智能合集.md)。
