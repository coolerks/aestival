## 2. 看板规则

- 开始任务前将状态改为“进行中”，补充负责人/工具和更新时间。
- “进行中”任务不能被另一会话静默接管。
- 被阻塞时写入 `依赖与风险.md` 并说明解除条件。
- 完成实现但尚未确认时使用“待验收”，不得提前写“已完成”。
- 完成后在“验收或结果”列写可验证结果，并在变更日志追加记录。
- 一个任务范围过大时拆出子任务，保留父任务作为汇总。
