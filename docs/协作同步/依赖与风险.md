# Aestival 依赖与风险

> 最后更新：2026-07-26 20:13
> 时区：Asia/Shanghai

## 1. 依赖

| ID | 依赖 | 状态 | 影响 | 解除条件 |
| --- | --- | --- | --- | --- |
| DEP-001 | shadcn 4.14.1 CLI 要求 Node.js ≥ 20.18.1，当前环境为 20.10.0 | 不阻塞当前实现 | 已生成组件和 production build 可用；后续再次运行 shadcn CLI 时会出现 engine 警告 | 将本地 Node.js 升级到 20.18.1 以上或当前 LTS |


## 2. 风险

| ID | 风险 | 级别 | 影响 | 缓解方式 |
| --- | --- | --- | --- | --- |
| RISK-001 | 当前前端 production 主 chunk 约 742 kB | 低 | 随管理页与编辑器能力增加，首屏加载体积可能继续上升 | 知识库页约 154 kB、会话管理 Dialog 约 15 kB、会话视图约 47 kB、Recharts 上下文控件约 306 kB、朗读控制条约 3 kB、应用草稿页约 4 kB，均已拆为按需 chunk；后续继续按管理页和重型能力动态导入，并在接入 Monaco 前评估手动分包 |
| RISK-002 | Wails 3 仍使用 alpha 版本 | 中 | 窗口 API 或平台行为可能随升级变化；当前 `Maximise()` 会主动禁用尺寸约束，macOS 原生拖角恢复又可能绕过 `UnMaximise()` | 窗口配置集中保留在 `main.go`；前端窗口适配层在最大化切换后显式恢复约束；升级前执行三平台窗口、标题栏和最小尺寸回归 |
| RISK-003 | 自动化原生窗口检查只能捕获缩放后的画面，不能逐帧量化拖动中的微抖 | 低 | 极短促的缩放抖动无法由最终截图发现 | 已关闭（2026-07-26）：第八轮移除 `InvisibleTitleBarHeight` 后用户实测确认角落缩放抖动根治；第十一轮收窄 `no-drag` 命中范围后，用户再次确认完整标题栏拖动正常且缩放修复无回归 |


## 3. 更新规则

- 依赖解除后更新状态和解除证据。
- 风险消失时标记“已关闭”，不要删除历史。
- 新风险必须包含影响和至少一个可执行缓解动作。
- 阻塞任务需同时在任务看板中标记“阻塞”。
