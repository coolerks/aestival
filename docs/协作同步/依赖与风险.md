# Aestival 依赖与风险

> 最后更新：2026-07-25 23:31  
> 时区：Asia/Shanghai

## 1. 依赖

| ID | 依赖 | 状态 | 影响 | 解除条件 |
| --- | --- | --- | --- | --- |
| DEP-001 | shadcn 4.14.1 CLI 要求 Node.js ≥ 20.18.1，当前环境为 20.10.0 | 不阻塞当前实现 | 已生成组件和 production build 可用；后续再次运行 shadcn CLI 时会出现 engine 警告 | 将本地 Node.js 升级到 20.18.1 以上或当前 LTS |


## 2. 风险

| ID | 风险 | 级别 | 影响 | 缓解方式 |
| --- | --- | --- | --- | --- |
| RISK-001 | 当前前端 production 主 chunk 约 616 kB | 低 | 随管理页与编辑器能力增加，首屏加载体积可能继续上升 | UI-002 之后按页面和重型能力使用动态导入与手动分包 |
| RISK-002 | Wails 3 仍使用 alpha 版本 | 中 | 窗口 API 或平台行为可能随升级变化 | 窗口配置集中保留在 `main.go`，升级前执行三平台窗口与标题栏回归 |
| RISK-003 | 自动化原生窗口检查只能捕获缩放后的画面，不能逐帧量化拖动中的微抖 | 低 | 极短促的左上角缩放抖动可能无法由最终截图发现 | 已避让 8px 原生缩放边缘并移除 fixed/动态视口层；UI-001 最终验收前对 `bin/aestival.app` 做一次人工连续左上角拖动 |


## 3. 更新规则

- 依赖解除后更新状态和解除证据。
- 风险消失时标记“已关闭”，不要删除历史。
- 新风险必须包含影响和至少一个可执行缓解动作。
- 阻塞任务需同时在任务看板中标记“阻塞”。
