## 3. 更新规则

- 依赖解除后更新状态和解除证据。
- 风险消失时标记“已关闭”，不要删除历史。
- 新风险必须包含影响和至少一个可执行缓解动作。
- 阻塞任务需同时在任务看板中标记“阻塞”。
