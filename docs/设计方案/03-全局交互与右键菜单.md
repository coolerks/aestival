# 全局交互与右键菜单

## 1. 交互原则

1. 同一动作在按钮、Command、右键菜单和快捷键中使用同一名称与图标。
2. 右键菜单针对当前对象，不展示与对象无关的动作。
3. 默认动作直接执行；不可逆、越权或高成本动作先确认。
4. 所有异步操作都有进行中、成功、失败和重试状态。
5. 鼠标、触控板和键盘均可完成核心路径。
6. 应用外壳、标题栏、侧栏、导航、工具栏、菜单和按钮默认不可框选文字；标题栏拖动区使用普通箭头光标。
7. 消息正文、文档/代码预览、输入与可编辑区域、Monaco、终端和日志等内容表面显式保留文本选择及复制能力。

## 2. 全局右键策略

应用根节点全局阻止浏览器原生 `contextmenu`。右键交互统一由 shadcn/ui `ContextMenu` 承载；普通点击触发的菜单使用 `DropdownMenu`。两者共享：

- 菜单项左侧 Lucide 图标。
- 右侧 `Kbd`/菜单快捷键。
- `ContextMenuSeparator`/`DropdownMenuSeparator` 分组。
- `Sub`/`SubContent` 多级菜单。
- Checkbox/Radio 项表达可切换状态。
- 破坏性操作使用 destructive variant。

例外不是“恢复原生菜单”，而是提供区域专用菜单：输入框、Monaco 和终端仍显示 Aestival 菜单，但保留这些区域应有的编辑动作。

### 2.1 快捷键显示

- macOS：`⌘`、`⌥`、`⇧`、`⌃`。
- Windows/Linux：`Ctrl`、`Alt`、`Shift`。
- 菜单根据当前平台动态显示，不同时显示两套。
- 快捷键被用户改绑后，菜单立即显示新绑定。
- 没有绑定的动作不显示空占位。

## 3. 右键菜单清单

以下表格中的每一行都是带图标的菜单项；“—”表示没有默认快捷键。

### 3.1 应用空白区

工作区主内容、知识库/应用/阅读/能力/任务/设置等管理页的无对象空白区默认不显示右键菜单。全局搜索、命令和布局动作分别通过标题栏按钮、快捷键与 `Command` 入口提供，避免在每个页面重复展示同一组全局动作。

只有明确绑定对象的区域才注册 `ContextMenu`：会话/项目、应用卡片、阅读文章、管理列表行、文件树、文件页签、文件预览、终端、聊天消息和 Monaco 编辑器。对象菜单只保留与当前对象相关的动作。

## 4. 全局 Command

### 4.1 唤起方式

- 标题栏 Search 按钮。
- `⌘/Ctrl+K`：直接进入全局搜索。
- `⌘/Ctrl+Shift+P`：直接进入动作命令。
- 输入框行首 `/`：进入仅面向会话的 Slash Command，不打开全局层。

### 4.2 结构

`Dialog` 内使用 `Command`：

1. 搜索输入。
2. 最近项目与会话。
3. 匹配分组。
4. 右侧可选预览。
5. 底部键盘帮助。

搜索分组：

- 功能与页面。
- 动作与设置。
- 项目与文件。
- 项目类型、笔记、大纲动作和全局图谱；同名笔记显示根目录与相对路径。
- 会话。
- 聊天记录。
- 知识库条目。
- 应用、阅读合集、Skill、智能体和任务。

阅读结果只包含“打开阅读”和合集导航，不把文章标题、摘要或正文纳入本轮全局内容索引。阅读页内搜索保持独立，并始终按发布时间倒序展示匹配项。

空查询展示最近使用与建议动作；有查询时展示本地索引结果。每个结果显示类型图标、主标题、上下文路径和匹配摘要。

### 4.3 键盘行为

- `↑/↓` 移动。
- `Enter` 打开。
- `⌘/Ctrl+Enter` 在侧边打开。
- `Tab` 切换结果/预览区域。
- `Esc` 先清空查询，再关闭 Dialog。
- 搜索文本与历史不发送给模型。

## 5. 拖拽与投放

- 系统文件拖入输入框：生成 `AttachmentNew`，不自动发送。
- 文件树拖入消息：添加为当前草稿附件。
- 会话拖到项目：移动会话，Hover 600ms 自动展开项目。
- 面板页签拖到右侧/底部投放区：移动面板。
- 文件页签可重新排序，但聊天页签位置锁定。
- 笔记页签沿用编辑组跨组移动/复制；四种编辑模式不作为可拖动的二级页签。
- 阅读自定义合集只在自定义区域内重排；“精选”“全部”不接受投放，来源不能拖入 AI 合集来改变其定义。
- 拖拽时显示真实投放区域、目标名称和禁止状态；不只改变鼠标指针。

## 6. 反馈与确认

| 情况 | 组件 | 规则 |
| --- | --- | --- |
| 保存、复制、Star、已加入上下文 | `Sonner` | 短反馈，可提供“撤销” |
| 连接失败、权限风险、上下文接近上限 | `Alert` | 持续到问题解决 |
| 删除、断开、取消订阅、清空、绕过审批 | `AlertDialog` | 明确对象、后果与主按钮；取消订阅默认保留历史并提供显式删除选项 |
| 复杂创建/编辑 | `Dialog` / `Sheet` / `Drawer` | 宽度按内容与窗口切换 |
| 短时加载 | `Spinner` | 出现在触发动作附近 |
| 页面骨架加载 | `Skeleton` | 结构稳定，避免跳动 |
| 列表为空 | `Empty` | 解释原因并给主动作 |

禁止使用浏览器 `alert()`、`confirm()`、`prompt()`。

## 7. 焦点与无障碍

- 打开菜单时焦点落到当前项；关闭后返回触发元素。
- 打开 Dialog/Sheet 时形成焦点圈；Escape 关闭最上层浮层。
- 不允许浮层关闭后焦点丢到 `body`。
- 树、Tabs、菜单和 ToggleGroup 使用方向键移动。
- 纯图标按钮必须有 Tooltip，但 Tooltip 不作为唯一说明。
- 删除、审批、运行状态通过文本和图标共同表达。
- 右键菜单也可通过 `Shift+F10` 或键盘菜单键打开。
