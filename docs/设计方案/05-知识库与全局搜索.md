# 知识库与全局搜索

## 1. 知识库目标

知识库页面负责两类能力：

1. 管理数据库、向量库与本地文件连接。
2. 把连接中的内容组织为可检索知识库，并验证检索结果。

“连接”与“知识库”分开：连接描述数据从哪里来；知识库描述选取哪些内容、如何切分/嵌入、如何检索以及哪些智能体可使用。

## 2. 页面结构

知识库页顶层使用 `Tabs`：

- 知识库
- 数据连接
- 检索测试
- 同步记录

页面头部：

- Breadcrumb。
- 标题与说明。
- 主动作随 Tab 变化：“新建知识库”或“新建连接”。
- 全局状态 Alert：离线、嵌入模型不可用、失败同步等。

## 3. 知识库首页

### 3.1 统计区

默认使用一条由 `Item + Separator` 组成的紧凑指标带：

- 知识库总数。
- 已索引条目。
- 待同步来源。
- 最近 24 小时检索次数。

指标不是导航替代物，点击仅应用对应筛选。只有在宽屏且某项需要独立操作时，才可将最多 4 项改为并列 Card；不能在页面外层 Card 内再放指标 Card。

### 3.2 工具栏

- `Command` 搜索名称、来源、标签。
- `Combobox` 筛选连接类型。
- `Select` 筛选状态。
- `ToggleGroup` 列表/网格视图。
- 排序 Dropdown：最近更新、名称、条目数、检索次数。

### 3.3 知识库卡片/列表

每项显示：

- 名称与说明。
- 来源连接与类型。
- 嵌入模型。
- 文档/记录/向量数量。
- 最近同步。
- 状态 Badge：就绪、同步中、需更新、错误、已停用。
- “测试检索”次动作。
- 更多菜单。

默认列表使用 `DataTable`；用户切换到网格时，独立知识库对象可使用 `Card`。Card 内只放字段、Badge 和动作，不再嵌套统计卡或结果卡。右键菜单遵循管理页通用模式，并增加“在当前会话中使用”。

## 4. 支持的数据源

| 类型 | 连接图标 | 预期检索模式 | 创建时关键字段 |
| --- | --- | --- | --- |
| PostgreSQL | `Database` | 关系查询、向量查询 | Host、Port、Database、Schema、SSL、凭据、向量扩展状态 |
| MySQL | `Database` | 关系查询、向量查询 | Host、Port、Database、SSL、凭据、向量能力检测 |
| Milvus | `Waypoints` | 向量查询 | URI、Database、Collection、Token/TLS |
| Weaviate | `Waypoints` | 向量/混合查询 | Endpoint、Class/Collection、API Key |
| Chroma | `Waypoints` | 向量查询 | 本地路径或 Endpoint、Collection |
| Elasticsearch | `SearchCheck` | 文本、向量、混合查询 | Endpoint、Index、认证、TLS |
| Redis | `DatabaseZap` | Key/文档、向量查询 | Host、Port、Database、认证、TLS、Index |
| Oracle | `Database` | 关系查询、向量查询 | Host、Port、Service/SID、Schema、Wallet/TLS、凭据 |
| 文件 | `Files` | 切片嵌入、元数据过滤 | 文件/目录、包含与排除规则、同步方式 |

具体连接测试后，用能力 Badge 展示驱动实际支持的检索模式；不在测试前假定某个服务器版本一定支持向量能力。

## 5. 新建连接

使用 `Dialog` 或宽 `Sheet` 的四步向导，移动到窄窗口时使用 `Drawer`。

### 第一步：选择类型

- 使用 `Item` 选择网格展示九种类型；当前选中项用边框和选中标记表达，不使用 Card 套 Card。
- 支持按“关系数据库”“向量数据库”“搜索引擎”“本地文件”筛选。
- 每项包含能力说明，不展示营销文案。

### 第二步：连接配置

- 使用 `Field`、`Input`、`InputGroup`、`Select`、`Checkbox`、`Switch`。
- 名称必填；同一类型可创建多个连接并设置别名。
- 密码/API Key 使用密码输入，默认不回显。
- 提供“从环境变量引用”，只保存变量名，不展示变量值。
- SSL/TLS 设置放在 Accordion。
- 高级参数放在 Accordion，不干扰主流程。

文件连接改为：

- 选择文件或文件夹。
- 包含 glob。
- 排除 glob。
- 是否跟随符号链接。
- 单文件大小上限。
- 自动同步方式。

### 第三步：测试连接

Progress 步骤：

1. 地址解析。
2. 认证。
3. 权限。
4. 版本与能力探测。
5. 可选向量能力探测。

结果用 Alert 展示；失败信息提供“复制诊断”，自动脱敏密码、Token 和连接串敏感字段。

### 第四步：确认

- 展示别名、类型、地址、能力与本地存储策略。
- 默认只读。
- 明确“测试成功不代表已创建知识库”。
- 创建成功后提供“创建知识库”和“稍后”。

## 6. 连接管理

连接列表使用 DataTable：

| 列 | 内容 |
| --- | --- |
| 名称 | 别名、类型图标 |
| 地址 | 脱敏后的 Host/路径 |
| 能力 | 关系、向量、全文、混合 Badge |
| 使用中 | 关联知识库数量 |
| 状态 | 在线、离线、认证失败、未测试 |
| 最近测试 | 相对时间 |
| 动作 | 测试、编辑、更多 |

连接详情使用 Tabs：

- 概览。
- 关联知识库。
- 权限。
- 测试与诊断。
- 使用记录。

断开或删除连接前显示受影响的知识库；允许“只移除连接配置”或“同时移除本地索引”，二者后果分开说明。

## 7. 新建知识库

使用五步向导。

### 7.1 基本信息

- 名称。
- 说明。
- 图标/颜色标记（从有限预设中选择，不上传头像）。
- 可使用范围：所有智能体或指定智能体。

### 7.2 选择来源

- 选择已有连接或直接新建连接。
- 数据库来源继续选择 Schema/Table/View/Collection/Index。
- 文件来源可预览包含与排除结果。
- 数据库默认只读；关系检索允许保存参数化查询模板，不允许在 UI 中默认执行写语句。

### 7.3 内容与元数据

文件：

- 内容解析器。
- 标题字段。
- 路径、修改时间、标签等元数据。

数据库：

- 主键。
- 要嵌入的文本字段。
- 可过滤字段。
- 展示字段。
- 增量同步字段。
- 关系查询模板。

### 7.4 嵌入与切分

- 嵌入模型 `Combobox`。
- Chunk 大小 `Slider + Input`。
- Overlap `Slider + Input`。
- 分隔策略 Select。
- 批大小。
- 重排模型可选。
- 预览 3 个实际切片，使用 Carousel 浏览。

如果目标连接已存向量，可选择“使用已有向量”并指定向量字段与维度；UI 校验维度与模型是否匹配。

### 7.5 同步与确认

- 手动、启动时、定时同步。
- 定时同步可跳转复用任务调度器。
- 展示预计条目数、索引空间和嵌入费用；无法估算时明确标注。
- 创建后打开详情并展示初次同步 Progress。

## 8. 知识库详情

Tabs：

### 概览

- 状态、来源、模型、索引大小、最近同步。
- 最近检索 Chart。
- 快捷动作：同步、测试检索、编辑。

### 内容

- DataTable 展示文档/记录。
- 搜索、元数据筛选、分页。
- 点击行打开 Sheet：原文、切片、向量元数据、来源定位。
- 支持重新嵌入单项、排除单项。

### 检索配置

- Top K。
- 相似度阈值。
- 混合检索权重。
- 重排开关与模型。
- 元数据过滤默认值。
- 结果去重。

### 同步

- 同步策略。
- 上次/下次同步。
- 增量游标。
- 同步历史与错误行。
- “立即同步”“取消同步”。

### 权限

- 允许的智能体。
- 是否允许代理自动检索。
- 是否允许查看完整来源。
- 数据脱敏规则。

## 9. 检索测试

检索测试页使用三部分：

1. 顶部查询输入与知识库多选。
2. 左侧检索参数。
3. 右侧结果与调试信息。

结果默认使用连续 `Item` 列表；用户切换“大预览”时单条结果可使用独立 Card，显示：

- 排名。
- 综合分数、向量分数、关键词分数、重排分数。
- 来源与定位。
- 命中片段。
- 元数据。
- “添加到当前会话”。

右上 ToggleGroup 切换“结果”“原始 JSON”“查询过程”。查询过程只展示可观察步骤，不暴露凭据。

## 10. 同步记录

DataTable 列：

- 知识库。
- 触发方式。
- 开始/结束时间。
- 扫描、创建、更新、删除、失败数量。
- 嵌入 token/估算费用。
- 状态。
- 详情。

失败任务可“重试失败项”；批量清理历史使用 AlertDialog。

## 11. 全局搜索

全局搜索使用 `Command + Dialog`，属于所有页面之上的悬浮层。

### 11.1 初始状态

空查询时显示：

- 最近会话。
- Star 会话。
- 最近功能。
- 最近搜索词（可在设置中关闭并清空）。

### 11.2 搜索范围

| 分组 | 内容 | 结果信息 |
| --- | --- | --- |
| 功能 | 页面、动作、设置项 | 图标、名称、快捷键 |
| 会话 | 标题、项目、模型、标签 | 项目路径、时间、状态 |
| 聊天记录 | 用户/AI 消息正文 | 会话、发送者、匹配摘要、日期 |
| 项目与文件 | 项目名、文件名、路径 | Material 文件图标、相对路径 |
| 知识库 | 名称、内容索引 | 来源、命中片段 |
| 能力 | MCP、Skill、智能体、指令、Hooks | 类型、状态 |
| 应用与任务 | 应用、定时任务 | 状态、下次运行 |

用户要求的“全局功能、会话、聊天记录”始终置于前三组，其余分组可在搜索设置中关闭。

### 11.3 搜索交互

- 输入即时搜索本地索引；远程/数据库结果需显式切换“扩展搜索”。
- 支持前缀：`>` 动作、`@` 会话、`#` 知识库、`:` 设置。
- `Enter` 打开。
- `⌘/Ctrl+Enter` 在不关闭 Command 的情况下侧边预览。
- 消息结果预览显示前后各一条上下文，点击定位并高亮。
- 长结果分页/渐进加载，每组先展示 5 项。
- 底部“查看全部结果”打开全尺寸 Dialog 结果视图，而不是新增常驻顶层页面。

### 11.4 隐私与索引状态

- 索引在本地构建。
- 临时会话默认不进入索引。
- 设置可排除项目、文件类型、会话或知识库。
- 索引未完成时显示 Progress 和当前范围。
- 搜索历史可单条删除或全部清空。
- 无结果时建议检查筛选、索引状态或改用内容搜索面板。

## 12. 页面状态

| 状态 | 知识库页 | 全局搜索 |
| --- | --- | --- |
| 空 | Empty + 新建知识库/连接 | 最近项目与功能 |
| 加载 | 结构化 Skeleton | 行内 Spinner |
| 同步中 | Progress + 可取消 | 结果标记“索引更新中” |
| 部分失败 | Alert + 失败项 | 已有结果仍可用 |
| 离线 | 本地文件/索引可用，远程连接禁用 | 仅搜本地索引 |
| 权限不足 | 说明缺少的权限与修复入口 | 不泄露不可见内容 |
| 成功 | Sonner + 打开详情 | 打开目标后关闭 |
