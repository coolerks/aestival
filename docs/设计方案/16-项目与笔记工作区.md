# 项目与笔记工作区

> 任务：DOC-007
> 日期：2026-08-11
> 状态：待用户验收
> 范围：项目创建、双类型工作区、笔记编辑与知识能力的 UI/交互/状态/前端 Mock 规格；不实现真实持久化、目录扫描、文件读写、索引、图谱计算、图片生成或业务后端

## 1. 目标与范围

Aestival 的左侧栏“项目”从只展示既有项目，扩展为可以创建两种不可转换的工作区：

- `项目`：保留当前代码/通用文件工作区能力，继续使用 Monaco、终端、日志、会话调试和项目看板。
- `笔记`：面向 Markdown 知识工作，提供四种编辑模式、文件面板、大纲、反向链接、标签与属性、全局/局部知识图谱，并限制可用面板和代理能力。

两种类型都保留现有项目—会话层级和固定“聊天”页签。用户可以在笔记项目的聊天页签中使用代理协助整理内容，但工具权限必须受笔记根目录与动作白名单约束。

本设计的目标：

1. 让用户从“项目”标题行直接创建工作区，并一次组织一个或多个根文件夹。
2. 保持普通项目的现有工作区行为不回归。
3. 让笔记模式成为完整但克制的 Markdown 工作区，而不是在 Monaco 上继续拼装半成品编辑器。
4. 让笔记、链接、图谱和代理动作具有清晰的文件身份、权限边界与失败状态。
5. 为 UI-024 提供诚实的前端 Mock 范围，不把目录选择误写成目录扫描或文件服务完成。

### 1.1 本轮不做

- 不修改前端、Go、Wails 协议、依赖或锁文件。
- 不安装 Vditor、Cytoscape.js 或其他包。
- 不持久化项目，不扫描或监听用户选择的目录。
- 不读取、写入、重命名、移动或删除真实文件。
- 不建立真实 Markdown 链接索引，不计算真实知识图谱。
- 不执行 Shell、构建、调试、项目看板或图片生成动作。
- 不把笔记模式扩展为数据库、白板、协同编辑或云同步产品。

## 2. 稳定术语

| 术语 | 定义 |
| --- | --- |
| 项目类型 | `项目` 或 `笔记`；创建后不可转换。 |
| 根目录 | 一个工作区允许访问的顶层本地文件夹；同一工作区可包含多个根目录。 |
| 默认根目录 | 新文件、附件以及普通项目终端默认使用的一个根目录；每个用户创建的工作区必须且只能指定一个。 |
| 项目模式 | `kind = project` 的通用文件与开发工作区，沿用现有工作区面板和 Monaco 规格。 |
| 笔记模式 | `kind = note` 的 Markdown 知识工作区，只开放本设计明确允许的文件、搜索、编辑和知识能力。 |
| Markdown Buffer | 同一笔记在多个编辑组之间共享的内存文本工作副本，不等同于已保存文件。 |
| 全局图谱 | 作为主内容页签打开的当前笔记项目全量关系视图。 |
| 局部图谱 | 右侧栏中围绕当前笔记按深度展开的关系视图。 |
| 已链接提及 | 通过标准 Markdown 链接或 `[[WikiLink]]` 明确指向当前笔记的提及。 |
| 未链接提及 | 正文中出现当前笔记标题或别名，但尚未形成显式链接的文本匹配。 |

固定“任务”仍是系统项目，不参与“至少一个根目录”的创建校验，也不允许改成笔记类型。

## 3. 编辑器与图谱技术选择

### 3.1 Markdown 编辑器选择 Vditor

笔记模式使用 [Vditor](https://b3log.org/vditor) 作为 Markdown 编辑内核，不自行实现 Markdown 解析、输入法组合、撤销栈、选区映射、表格编辑、粘贴、快捷键和源码/渲染同步。

选择依据：

| 方案 | 与本需求的匹配 | 结论 |
| --- | --- | --- |
| Vditor | 官方能力覆盖 `sv` 分屏、`ir` 即时渲染、只读 `Vditor.preview()`、大纲与 React 集成方式，能够用同一 Markdown 数据支撑四种模式 | 采用 |
| Tiptap | 适合深度定制结构化富文本，但官方 Markdown 能力仍标记为 Beta；要补齐源码、分屏、即时渲染与 Markdown 往返需要额外工程 | 本阶段不采用 |
| 自研编辑器 | 必须自行处理 Markdown AST、输入法、选区、撤销、粘贴、表格、快捷键和渲染安全 | 禁止 |

Vditor 的 [模式示例](https://b3log.org/vditor/demo/option-mode.html) 与 [预览接口](https://b3log.org/vditor/demo/preview.html) 是四模式映射的实现依据；Tiptap 对比只参考其官方 [Markdown 文档](https://tiptap.dev/docs/editor/markdown/examples)。

### 3.2 Vditor 集成边界

- 依赖必须来自本地 npm 安装和本地构建产物，不加载 CDN 脚本、样式、图标或字体。
- 首次打开 Markdown 编辑表面时动态加载，不能并入应用首屏主包。
- 关闭 Vditor 自身持久缓存，配置 `cache.enable = false`；工作区恢复只保存安全的 UI 定位，不保存第二份正文。
- Vditor 负责编辑内核和 Markdown 渲染；模式切换、页签、工具栏、菜单、对话框、提示和面板仍由 shadcn/ui 组合。
- Aestival 的外层工具栏使用 `ToggleGroup`、`ButtonGroup`、`DropdownMenu`、`Tooltip` 和 `Dialog`，不复制一套与 Vditor 重叠的富文本状态机。
- Vditor 表面适配 `bg-background`、`text-foreground`、`text-muted-foreground`、`border-border`、`ring-ring` 等语义 token；不能把第三方默认亮色主题作为独立视觉岛。
- React 生命周期由独立适配层管理：挂载后创建实例，切换页签只在需要时恢复，卸载前销毁；异步导入返回时必须校验宿主仍有效，避免 Strict Mode 重复初始化、已卸载节点回写或多个实例争用同一容器。
- 编辑器回调只提交 Markdown Buffer 变更和安全视图状态；Vditor 实例、DOM、解析树、渲染 HTML、上传对象和选区对象不进入普通 Zustand 持久化。

### 3.3 图谱选择 Cytoscape.js

全局图谱和局部图谱使用动态加载的 [Cytoscape.js](https://js.cytoscape.org/index.html) 承载布局、缩放、平移、命中测试和节点/边交互，不自行实现图布局或 Canvas/SVG 交互引擎。

- 只有首次打开全局或局部图谱时加载 Cytoscape.js 和所选布局扩展。
- Cytoscape 实例、布局对象、DOM、像素位置缓存和动画对象不进入 Zustand 持久化。
- Zustand 只保存图谱查询、筛选、选中节点 ID、局部深度、视口偏好和 Adapter 返回的可序列化快照。
- 图谱画布必须配套同步节点列表；键盘和读屏用户不依赖画布命中才能搜索、选择和打开笔记。

## 4. 左侧栏“添加项目”入口

### 4.1 标题行加号

“项目”组标题行右侧使用 shadcn `SidebarGroupAction`，图标使用 Lucide `Plus`：

- 默认鼠标状态不显示，避免项目区常驻多一个高对比动作。
- 当整个项目组 Hover、加号获得 `focus-visible`、组内进入 `focus-within` 时显示。
- 在不支持 Hover 的触摸/粗指针设备上始终显示，不能把创建入口变成 Hover-only。
- 可见与隐藏只改变透明度和命中状态，不改变标题行宽度，避免项目名称或滚动条抖动。
- `aria-label="添加项目"`；Tooltip 显示“添加项目”和平台化快捷键。
- 快捷键沿用 `⌘/Ctrl+Shift+O`；侧栏项目区和全局 Command 的“添加项目”调用同一动作。
- 点击后打开“添加项目”Dialog；关闭后焦点返回加号或原始命令入口。

### 4.2 对话框结构

“添加项目”使用 `Dialog + Field + RadioGroup + Item`，不使用 Card，也不在 Dialog 内模拟卡片：

1. 可访问标题“添加项目”和简短说明。
2. 名称 Field。
3. 类型 RadioGroup，包含两个 `Item`：`项目`、`笔记`。
4. 根目录 Field：已选择目录列表、添加文件夹按钮、空状态和就地错误。
5. 默认根目录 Field：在已选根目录中单选。
6. Footer：取消、添加项目。

类型说明必须直接展示不可转换的后果：

- 项目：文件、终端、搜索、日志、会话调试和项目看板。
- 笔记：Markdown 编辑、预览、大纲、反向链接、标签/属性和知识图谱；不提供终端、日志、会话调试和项目看板。

不能只靠图标或 Tooltip 表达类型差异。类型一旦创建不提供转换入口；未来如需迁移，必须另行设计显式导出/新建流程。

### 4.3 根目录选择

文件夹选择由未来 `ProjectFolderPickerAdapter` 调用 Wails 原生目录选择器。交互规则：

- 用户可以多次点击“添加文件夹”，每次取消都不改变已选列表。
- Adapter 可按平台能力返回一个或多个目录；UI 始终把结果追加到同一暂存列表，最后统一提交。
- 每个目录用 `Item` 展示显示名、标准化路径、可用性和“设为默认/移除”动作。
- 首个有效目录自动成为默认根目录；添加更多目录后可改选，但始终只能有一个默认项。
- 目录选择只取得用户明确选择的路径/安全标识，不扫描子目录、不计算文件数、不建立索引。
- 选择器加载时只禁用重复触发，不清空表单；失败在根目录 Field 就地显示并允许重试。

参考 [Wails 文件对话框](https://v3.wails.io/features/dialogs/file/)；展示组件不得直接调用 Wails runtime。

### 4.4 创建校验

提交前按以下顺序校验，并在对应 `Field` 同时设置 `data-invalid` 与 `aria-invalid`：

| 校验 | 规则 | 反馈 |
| --- | --- | --- |
| 名称 | 去除首尾空白后不能为空 | “请输入项目名称” |
| 类型 | 必须选择 `项目` 或 `笔记` | “请选择项目类型” |
| 根目录数量 | 用户创建的两种类型都至少一个有效根目录 | “请至少添加一个文件夹” |
| 重复目录 | 同一标准化/规范化路径只允许一次；按平台文件系统处理大小写 | “这个文件夹已经添加” |
| 父子重叠 | 同一项目中不能同时加入祖先目录和它的任意后代目录 | 指明冲突的两条路径，并保留用户选择以便调整 |
| 默认目录 | 必须指向当前列表中的一个有效根目录 | “请选择默认根目录” |
| 可用性 | 目录选择结果失效或权限不足时不能提交 | 展示失效路径和“重新选择” |

父子重叠校验使用 Adapter 返回的规范身份与路径段关系，不能用字符串前缀判断；例如 `/work/app` 不是 `/work/application` 的父目录。符号链接、大小写、挂载点和平台路径分隔符由未来 Adapter 规范化，无法确认时拒绝提交并说明原因。

项目显示名称允许重复，内部由稳定 `projectId` 区分；侧栏 HoverCard 和项目设置显示根目录，避免同名项目无法辨认。

### 4.5 创建反馈与成功路径

状态顺序为 `idle → dirty → loading → ready/error`：

- 表单一旦被编辑进入 `dirty`。
- 提交时锁定会造成重复创建的字段和主按钮，按钮内显示 Spinner。
- 成功后关闭 Dialog，用 Sonner 显示“已添加项目”；UI-024 必须标注“仅本次运行”。
- 新项目成为当前项目，项目行展开，并按现有规则展示最近 5 个会话或会话 Empty。
- 主编辑组保持固定“聊天”页签；不自动创建第二个会话。
- 右侧栏打开“文件”。普通项目和笔记项目都执行这一规则。
- 笔记项目的底部面板默认关闭；普通项目仍沿用现有“首次展开默认终端”。
- 创建失败保留全部字段和已选目录，焦点移到错误摘要或首个无效 Field，不重复打开原生选择器。

UI-024 的“成功”只代表内存项目对象创建成功，不代表项目配置已经持久化、目录已经读取或文件已经索引。

## 5. 双类型工作区能力矩阵

| 表面/能力 | 项目模式 | 笔记模式 |
| --- | --- | --- |
| 项目层级 | 项目下展开会话，每次 5 条；固定“聊天”页签 | 同样保留会话层级和固定“聊天”页签 |
| 主内容 | 聊天 + 文件/代码/通用预览/应用页签 | 聊天 + Markdown/素材安全预览/全局图谱页签 |
| Markdown | 沿用 [09](./09-工作区面板与文件预览.md) 的 Monaco 源码/预览/并排模式 | 使用 Vditor 的源码/并排/即时/预览四模式 |
| 右侧栏 | 文件、终端、搜索、日志、会话调试、项目看板 | 文件、搜索、大纲、反向链接、标签与属性、局部图谱 |
| 底部面板 | 文件、终端、搜索、日志、会话调试 | 搜索、反向链接 |
| 非 Markdown | 沿用现有编辑和安全预览 | 图片、PDF、音视频安全预览；代码/纯文本只读；未知二进制仅元数据/安全查看 |
| 代理能力 | 沿用普通项目审批与能力策略 | 只允许根目录内文件操作、文件搜索、内容与图片素材生成；禁止 Shell、构建、调试和项目看板动作 |
| 项目看板 | 主内容入口与右侧面板可用 | 不显示入口，策略层也必须拒绝 |

笔记模式隐藏某项能力不等于获得安全边界；Adapter/权限策略必须对不可用动作返回明确拒绝，防止通过快捷键、Command、旧快照或代理调用绕过 UI。

## 6. 项目切换与工作区快照

### 6.1 每项目隔离

切换项目之前保存当前项目的安全工作区快照，切换后恢复目标项目自己的快照：

- 编辑组布局、比例和焦点组。
- 每组的页签顺序、活动页签、临时预览与 MRU。
- 右侧栏是否展开、当前面板、页签顺序和尺寸。
- 底部面板是否展开、当前面板、页签顺序和高度。
- 文件树展开节点的受限安全集合。
- 笔记编辑器模式、光标/选区/滚动定位引用。
- 图谱筛选、局部深度、选中笔记和视口偏好。

工作区类型不能互相污染：

- 从打开终端/日志/项目看板的普通项目切到笔记项目时，这些面板不出现。
- 切回原普通项目时恢复它自己的终端/日志/看板布局，但不恢复真实终端进程。
- 从笔记项目切到普通项目时，大纲、反向链接、标签/属性和局部图谱不出现。
- 旧快照含有当前类型不允许的面板时，过滤非法项并用一次性 Sonner 说明“已按项目类型恢复可用布局”。

### 6.2 默认与失败恢复

- 新普通项目：右侧默认“文件”；底部关闭，首次展开时创建“终端 1”。
- 新笔记项目：右侧默认“文件”；底部关闭，首次展开时创建“搜索”。
- 快照不存在或损坏：保留主编辑组“聊天”，恢复上述类型默认值。
- 已保存页签的资源不存在或根目录已失效：不伪造内容；移除失效临时页签，持久页签显示错误与“重新定位/关闭”。
- 项目切换只改变活动上下文，不移动既有会话、文件或工作项。

## 7. 笔记主内容与编辑组

### 7.1 页签规则

笔记项目沿用 [09](./09-工作区面板与文件预览.md) 的 VS Code 式独立编辑组：

- 主编辑组第一项固定“聊天”，不可关闭、不可拖动；其他编辑组不复制聊天。
- Markdown、素材预览和全局图谱都使用一级主内容页签，不建立二级页签。
- 全局图谱是当前笔记项目的单实例可关闭页签；重复打开只聚焦已有页签。
- 文件树在当前焦点组打开资源；单击为临时预览，双击、编辑或固定后转为持久页签。
- 同一笔记可以在多个编辑组中打开，内容共享但视图独立。
- 页签支持组内重排、跨组移动/复制、边缘拆分和同组去重；行为与 DEC-020 保持一致。

### 7.2 四种编辑模式

四种模式固定如下，模式切换使用单选 `ToggleGroup`：

| `NoteEditorMode` | 用户文案 | Vditor 映射 | 行为 |
| --- | --- | --- | --- |
| `source` | 源码 | `mode: "sv"`，仅显示编辑侧 | 单栏 Markdown 源码编辑 |
| `split` | 并排 | `mode: "sv"`，显示编辑与预览 | 源码与预览左右并排，同步滚动由 Vditor 提供 |
| `instant` | 即时 | `mode: "ir"` | Typora 式即时渲染，作为默认所见即所得体验 |
| `preview` | 预览 | `Vditor.preview()` | 只读渲染，不创建可编辑输入面 |

规则：

- 四种模式属于同一文件页签，切换不创建第二层页签，也不复制 Markdown Buffer。
- 不增加 Vditor `wysiwyg` 作为第五种用户模式；首版“所见即所得”专指 `ir` 即时渲染。
- 同一笔记在不同编辑组可以使用不同模式。例如左侧 `source`、右侧 `preview`，内容仍来自同一 Buffer。
- 每个编辑器实例独立保存模式、光标、选区、折叠与滚动位置；任何实例修改文本后，其他实例接收同一 Buffer 版本并尽量保持自己的视图位置。
- `preview` 不允许输入；从 `preview` 切回编辑模式时恢复该编辑器最近一次可编辑视图状态。
- 默认新打开笔记使用用户最近选择的笔记模式；首次使用默认 `instant`。该偏好只决定新实例，不强制改写已打开编辑器。
- `split` 需要保持源码和预览可用的最小宽度；空间不足时先建议收起侧栏/右侧栏，并允许用户切换模式，不能静默把持久模式改成 `source`。

### 7.3 Buffer、保存与冲突

- 笔记身份使用 `rootId + relativePath`；所有编辑组引用同一 `NoteBufferId`。
- Buffer 保存源 Markdown、版本号、dirty 状态与最近保存摘要；不保存渲染 HTML、Vditor DOM 或完整第二份正文到普通持久化。
- 任一编辑器修改后，文件页签和所有引用实例同步显示脏状态。
- 保存状态为 `dirty → loading → ready/error`；UI-024 只显示明确的 Mock 保存反馈，不写真实文件。
- 未来真实保存必须通过 `NoteWorkspaceAdapter` 原子写入并检查外部版本；冲突进入比较/保留本地/重新加载流程，不静默覆盖。
- 最后一个脏引用关闭时使用保存/不保存/取消 Dialog；关闭一个仍有其他引用的编辑器不重复确认。

## 8. 笔记文件面板与文件可用性

### 8.1 多根目录文件树

笔记“文件”面板展示当前项目的全部根目录：

- 每个根目录是一级普通 Section/Collapsible，显示名称、相对身份和默认根目录 Badge；不使用 Card 包裹。
- 根目录内部使用 Material Icon Theme 映射和 [09](./09-工作区面板与文件预览.md) 的文件树键盘行为。
- 同名根目录显示足够的路径片段；完整路径只在 HoverCard、属性或复制路径动作中出现。
- 新建笔记默认放入当前选中文件夹；没有选中位置时使用默认根目录。
- 搜索、反向链接和图谱结果始终带根目录名/相对路径，避免多根目录重名误判。

### 8.2 文件动作

文件面板必须为以下动作提供完整 UI 状态，但 UI-024 不执行真实写入：

| 对象 | 动作 | 主要组件/反馈 |
| --- | --- | --- |
| 文件夹/空白 | 新建笔记 | `Dialog + Field`；自动补 `.md`，冲突就地校验 |
| 文件夹/空白 | 新建文件夹 | `Dialog + Field` |
| 文件/文件夹 | 重命名 | 就地输入或 Dialog；显示链接可能受影响的持续 Alert |
| 文件/文件夹 | 移动 | `Dialog + Command` 选择当前项目内目标；目标越界禁用 |
| 文件 | 复制路径 | `DropdownMenu`：绝对路径、根目录相对路径、文件名 |
| 文件/文件夹 | 移到废纸篓 | `AlertDialog` 明确对象、链接影响与不可用状态 |

笔记文件夹菜单移除“在此处打开终端”。代码与纯文本文件菜单不提供编辑方式，只有只读打开、复制路径、加入对话和系统定位等适用动作。

### 8.3 文件类型矩阵

| 文件类型 | 笔记模式行为 |
| --- | --- |
| `.md`、`.markdown` | Vditor 四模式编辑 |
| 图片 | 安全解码、缩放、元数据和加入对话；不执行嵌入脚本 |
| PDF | 沿用文档安全预览，只读 |
| 音频/视频 | 本地媒体安全预览，只读，不自动播放 |
| 代码、配置、纯文本 | Monaco 或安全文本查看器只读；允许查找、复制和加入对话 |
| Office | 沿用已登记安全预览产物；未登记时显示不可用，不在线转换 |
| SVG/HTML | 源码或清洗后的安全预览，不运行脚本和外部资源 |
| 可执行/未知二进制 | 元数据、哈希/Hex 安全入口；绝不执行 |

文件可用性必须区分：

- `idle`：尚未请求目录内容。
- `loading`：正在获取安全描述或 Mock 样例。
- `ready`：全部根目录可用。
- `partial`：部分根目录或部分文件描述不可用，已成功部分仍可浏览。
- `error`：当前目标不可读取；说明原因和重试/重新选择动作。

## 9. 笔记知识面板

### 9.1 大纲

右侧“大纲”面板基于当前活动 Markdown Buffer：

- 展示 H1–H6 的真实层级，不把粗体或字号猜成标题。
- 当前光标或预览视口所在章节高亮；编辑和预览模式使用各自定位适配。
- 提供大纲搜索、全部展开/收起和逐层折叠。
- 点击标题定位当前编辑器实例，不改写其他编辑组的滚动位置。
- 标题变化时增量更新；解析中保留上一次成功大纲并显示局部 Spinner。
- 没有标题时使用 Empty：“当前笔记没有标题”，提供插入一级标题的 Mock 动作。

### 9.2 反向链接

反向链接可位于右侧栏或底部面板，同一时刻默认单实例；移动前后共享索引结果，右/底槽位分别保存展开和滚动恢复状态：

- “已链接提及”：显示来源笔记、根目录、相对路径、标题层级和上下文片段。
- “未链接提及”：按当前笔记标题和显式别名查找文本匹配，单独分组，不自动创建图谱边。
- 点击结果在当前焦点编辑组打开来源并定位；修饰键可在相邻组打开。
- “转换为链接”属于文件写入动作，未来通过 `NoteWorkspaceAdapter` 并受审批；UI-024 只展示 Mock 确认与结果。
- 索引 `partial` 时显示缺失根目录/文件数量，不能把部分结果标成完整。

### 9.3 标签与属性

右侧“标签与属性”面板合并两类信息：

- 标签：YAML Front Matter 中的 `tags` 和正文内联标签；支持搜索、筛选、点击查看同标签笔记。
- 属性：YAML Front Matter 的键值列表，提供字符串、数字、布尔、日期和列表的编辑入口。
- 未识别字段保持原值并以只读方式展示；不能因 UI 不认识类型而删除。
- 修改属性必须最终回写同一 Markdown Buffer，并尽量保留未知字段、顺序和正文边界；禁止用重新序列化整个 YAML 的方式静默丢失注释或自定义结构。
- Front Matter 解析失败时显示原始范围、错误行和“以源码模式打开”，不覆盖原文。

## 10. 知识图谱

### 10.1 数据语义

首版图谱的主节点只有笔记；标签、附件和孤立状态作为筛选笔记节点的条件，不额外生成标签/附件节点：

- 节点 ID：`rootId + relativePath`。
- 节点标题：Front Matter 标题或首个 H1；都缺失时使用文件名。
- 边：只来自标准 Markdown 文件链接和 `[[WikiLink]]`。
- 不根据文本相似度、模型判断、共同标签、同目录或共同附件生成关系。
- 孤立笔记可以显示/隐藏；隐藏孤立节点不删除索引。
- 标签筛选按节点标签；附件筛选可选择“含附件/不含附件”或具体附件类型。

这条边界参考 Obsidian 的 [图谱](https://obsidian.md/help/plugins/graph) 与 [反向链接](https://obsidian.md/help/plugins/backlinks) 模型，但 Aestival 不复制 Obsidian 插件 API。

### 10.2 多根目录链接解析与消歧

标准 Markdown 相对链接先以来源笔记所在目录解析，再限定到对应根目录。`[[WikiLink]]` 按以下顺序解析：

1. 显式包含根目录/相对路径的目标。
2. 来源所在根目录内的唯一相对路径或标题/别名匹配。
3. 当前项目其他根目录中的唯一匹配。
4. 多个候选时标记 `ambiguous`，不创建边。
5. 无候选时标记 `unresolved`，不创建虚构节点。

重名候选使用 `Command/Dialog` 展示“根目录名 + 相对路径 + 标题”，用户选择后将来可把源链接改写为显式目标。消歧结果必须进入索引事实或源文本，不能只保存在画布临时状态。

### 10.3 全局图谱

全局图谱作为主内容单实例页签，结构为普通工具栏 + 图谱画布 + 可折叠同步节点列表：

- 搜索笔记。
- 缩放、适配视图、重置布局。
- 筛选根目录、标签、附件、孤立节点和未解析链接状态。
- 点击节点在当前焦点编辑组打开笔记；双击可固定页签。
- 节点 HoverCard 显示根目录、相对路径、标签、入边/出边数量。
- 图谱和节点列表选择同步；节点列表支持键盘搜索、方向移动、Enter 打开和可见焦点。

### 10.4 局部图谱

局部图谱只位于右侧栏：

- 中心节点为当前活动笔记。
- 深度筛选支持 1、2、3 层，默认 1 层。
- 可只看入链、出链或双向。
- 切换活动文件时更新中心节点；用户已固定局部图谱时保留中心并显示固定状态。
- 当前文件不是 Markdown 时使用 Empty，并提供“返回最近笔记”。

### 10.5 图谱状态

| 状态 | 表现 |
| --- | --- |
| `idle` | 尚未加载索引；显示说明和“加载示例/开始索引”边界文案 |
| `loading` | 保持工具栏骨架，画布 Skeleton/Spinner；可取消 |
| `ready` | 展示完整 Adapter 快照和统计 |
| `partial` | 展示可用节点/边，同时用 Alert 列出缺失根目录、失败文件、歧义和未解析数量 |
| `error` | 保留筛选与最近成功摘要，说明错误并提供重试/打开索引详情 |
| 空数据 | 区分“没有 Markdown 笔记”“有笔记但没有链接”“筛选后没有节点”三种 Empty |

UI-024 只能渲染明确标记的示例图谱，不能根据用户选择的真实目录计算节点和边。

## 12. 代理与权限边界

### 12.1 模式与项目类型共同决策

| 会话模式 | 项目类型 | 允许能力 |
| --- | --- | --- |
| 聊天 | 任意 | 禁止所有工具、MCP、Skill、工作流、网络检索和副作用；只允许用户主动附加内容后的纯对话 |
| 代理 | 项目 | 沿用普通项目已授权工具与审批策略 |
| 代理 | 笔记 | 仅允许笔记工具集，并继续经过审批策略 |

笔记工具集允许：

- 列出、读取、搜索当前项目根目录内的文件。
- 在根目录内任意层级创建、修改、重命名、移动或移到废纸篓。
- 操作任意文件类型，以便保存图片、音视频、PDF 等素材；非 Markdown 文件在 UI 中仍按安全预览/只读规则展示。
- 生成文本内容和图片素材，并把结果写入经审批的根目录目标。

笔记工具集禁止：

- Shell、终端、脚本执行、可执行文件运行。
- 构建、测试、调试、包管理器和版本控制命令。
- 项目看板、甘特图和项目工作项动作。
- 访问任何根目录之外的路径或通过链接、别名、挂载解析逃逸。
- 以“预览”或“生成素材”为名执行 HTML、SVG 脚本、宏或二进制。

### 12.2 根目录安全

未来策略层必须在每个文件动作执行前：

1. 解析目标的规范路径和真实父目录。
2. 使用路径段/文件身份验证目标位于任一允许根目录内。
3. 对不存在的新文件验证最近存在父目录和最终目标组合。
4. 解析符号链接并拒绝指向根目录外的目标；无法确认时默认拒绝。
5. 拒绝 `..`、大小写/短文件名绕过、链接竞态和执行动作。
6. 把根目录 ID、相对路径、动作、审批结果和拒绝原因写入审计事件，但不记录无关正文或敏感文件内容。

UI 隐藏终端和看板只是第一层；Command、快捷键、恢复快照、旧会话动作和代理工具调用都必须经过同一策略。

## 13. 概念状态与接口

以下类型用于约束未来前端状态和 Adapter，不是本轮后端协议，也不要求逐字作为代码实现：

```ts
type ProjectKind = "project" | "note"

type WorkspaceStatus =
  | "idle"
  | "loading"
  | "ready"
  | "dirty"
  | "partial"
  | "error"

interface ProjectRoot {
  id: string
  displayName: string
  path: string
  canonicalIdentity?: string
  availability: "unknown" | "ready" | "unavailable"
}

interface WorkspaceProject {
  id: string
  name: string
  kind: ProjectKind
  roots: ProjectRoot[]
  defaultRootId: string
  createdAt: string
}

type NoteEditorMode = "source" | "split" | "instant" | "preview"

type NotePanelType =
  | "files"
  | "search"
  | "outline"
  | "backlinks"
  | "metadata"
  | "local-graph"

interface NoteEditorViewSnapshot {
  editorId: string
  noteId: string
  mode: NoteEditorMode
  cursorAnchor?: string
  selectionAnchor?: string
  scrollAnchor?: string
}

interface ProjectWorkspaceSnapshot {
  projectId: string
  projectKind: ProjectKind
  editorLayout: unknown
  editorViews: NoteEditorViewSnapshot[]
  rightPanel: {
    open: boolean
    activeType?: string
    orderedTypes: string[]
    size: number
  }
  bottomPanel: {
    open: boolean
    activeType?: string
    orderedTypes: string[]
    size: number
  }
}

interface NoteGraphNode {
  id: string // rootId + relativePath
  rootId: string
  relativePath: string
  title: string
  tags: string[]
  hasAttachments: boolean

}

  id: string
  sourceId: string
  targetId: string
  kind: "markdown-link" | "wiki-link"

```

`editorLayout` 在本设计中保持概念类型，实际实现应复用现有编辑组布局类型，不再建立与 UI-020 平行的第二套结构。

### 13.1 领域状态

| 状态域 | 状态 | 说明 |
| --- | --- | --- |
| 创建项目 | `idle/dirty/loading/ready/error` | `ready` 只表示当前 Adapter 创建成功 |
| 根目录/文件可用性 | `idle/loading/ready/partial/error` | `partial` 保留可用根目录并列出失败项 |
| 笔记编辑 | `idle/loading/ready/dirty/error` | dirty 属于共享 Buffer，视图状态按编辑器隔离 |
| 笔记索引 | `idle/loading/ready/partial/error` | partial 必须报告缺失范围和索引版本 |
| 图谱 | `idle/loading/ready/partial/error` | 图谱不能比索引宣称更完整 |

状态对象统一携带适用的 `requestId/version/error/retryable/updatedAt`，避免慢请求覆盖新项目或新文件状态。不得用 `isLoading + hasError + isDirty` 等可能冲突的 boolean 代替明确状态。

### 13.2 Adapter 边界

```ts
interface ProjectFolderPickerAdapter {
  pickFolders(): Promise<ProjectRoot[]>
}

interface NoteWorkspaceAdapter {
  describeRoots(projectId: string): Promise<unknown>
  readFile(noteId: string): Promise<unknown>
  saveFile(command: unknown): Promise<unknown>
  moveEntry(command: unknown): Promise<unknown>
  trashEntry(command: unknown): Promise<unknown>
  subscribe(projectId: string, listener: (event: unknown) => void): () => void
}

interface NoteIndexAdapter {
  getOutline(noteId: string, bufferVersion?: number): Promise<unknown>
  getBacklinks(noteId: string): Promise<unknown>
  getMetadata(noteId: string): Promise<unknown>
  getGraph(projectId: string, query: unknown): Promise<unknown>
  getLocalGraph(noteId: string, query: unknown): Promise<unknown>
}
```

- 展示组件只调用领域动作/Store，不直接调用 Wails、文件系统、Vditor 静态方法或 Cytoscape 实例。
- `ProjectFolderPickerAdapter` 只负责目录选择与规范身份，不顺带扫描目录。
- `NoteWorkspaceAdapter` 是未来真实文件事实来源；所有写动作接受权限决策与版本信息。
- `NoteIndexAdapter` 只返回可序列化索引快照和完整度，不保存编辑器实例或文件正文副本。
- Vditor 与 Cytoscape 使用单独的组件适配层，不混入持久业务状态。

### 13.3 不进入普通 Zustand 持久化

- Vditor 实例、内部 undo 栈、DOM、选区对象、解析树和渲染 HTML。
- Cytoscape 实例、布局对象、像素坐标缓存和 Canvas/SVG DOM。
- PDF/媒体对象、Object URL、Canvas、音视频缓冲。
- 文件正文的第二份持久副本、完整目录扫描结果和二进制内容。
- 原生目录选择器句柄、Wails runtime 对象和文件监听器。
- 代理审批对象中的敏感正文、执行句柄或根目录外路径探测结果。

## 14. UI-024 前端 Mock 边界

UI-024 允许：

- 通过真实 Wails 原生目录选择器取得用户主动选择的目录标签/路径，用于创建表单展示与校验。

- 模拟内容/图片素材生成的请求与权限说明，但结果必须标注为示例，不产生文件或图片。

UI-024 禁止：

- 声称项目已跨重启保存或目录已监听。

真实目录选择后的文件面板应显示“文件读取服务尚未接入”的诚实 Empty；示例文件树只能属于明确标注的“示例笔记项目”，不能伪装成用户目录内容。

## 15. 右键、Command 与快捷键补充

### 15.1 项目对象

项目右键根据类型裁剪：

- 通用：在文件面板中显示、在系统文件管理器中显示、在此项目中新建任务、重命名、项目设置、复制路径、会话子菜单、从侧栏移除。
- 普通项目：打开项目看板、新建终端。
- 笔记项目：打开全局图谱、新建笔记、搜索笔记；不显示终端和项目看板。
- 固定“任务”：继续隐藏重命名、项目设置和移除；不显示笔记动作。

### 15.2 笔记对象

笔记文件右键补充：

- 打开、在侧边打开。
- 模式子菜单：源码、并排、即时、预览。
- 查看反向链接、打开局部图谱。
- 添加到当前对话、复制根目录相对路径。
- 重命名、移动、复制路径、移到废纸篓。

图谱节点右键：打开、在侧边打开、设为局部图谱中心、复制相对路径、显示反向链接。图谱空白区不复用文件或项目菜单。

### 15.3 Command 与快捷键

- `⌘/Ctrl+Shift+O`：添加项目。
- `⌘/Ctrl+N`：在当前上下文新建任务；焦点在笔记文件面板时由 Command 明确区分“新建任务”和“新建笔记”。
- 建议为“新建笔记”“打开全局图谱”“切换笔记模式”提供可配置动作，但不预占与现有编辑器冲突的固定键位。
- Command 搜索结果始终显示项目类型和根目录上下文；同名笔记不能只显示文件名。

所有菜单项使用 Lucide 图标、分组和平台化快捷键；破坏性动作使用 `AlertDialog`，短反馈使用 Sonner。

## 16. 响应式、无障碍与视觉约束

- 960×640：左侧栏可收起，右侧栏/底部面板可恢复；打开 `split` 时优先让出侧栏和检查器空间，不产生整页横向溢出。
- 1280×800：默认左侧栏 + 主编辑区，可按需展开一个笔记右侧面板。
- 1440×900 及以上：允许左侧栏 + 主编辑区 + 右侧栏；底部面板仍是垂直分割，不形成第四列。
- 添加项目 Dialog 在窄高度内只让正文滚动，标题/Footer 稳定；焦点环不被裁切。
- Hover 加号在键盘焦点和无 Hover 设备上可见；不能仅靠鼠标发现。
- Vditor 可编辑面、源码、预览、反向链接上下文和图谱节点列表显式恢复文本选择。
- 图谱不能仅用颜色表达根目录、选中、错误或边类型；节点列表提供文字等价信息。
- `prefers-reduced-motion` 下关闭图谱连续布局动画和非必要面板过渡。
- 大纲树、文件树、Tabs、模式 ToggleGroup、图谱节点列表和所有菜单支持方向键、Enter、Escape 与可见焦点。
- 纯图标按钮均有 `aria-label` 和 Tooltip；Dialog 有可访问标题，关闭后焦点返回触发元素。
- 页面结构使用普通 Section、Item、Separator、Tabs、Resizable 和 ScrollArea；不把根目录、模式、面板、图谱工具栏或属性区包装成 Card。
- 禁止 Card 套 Card 和视觉卡片嵌套；图谱节点画布、文件行与反向链接行也不能退化成“卡片墙”。

## 17. 状态与错误验收场景

必须覆盖：

1. 项目标题行默认隐藏加号，组 Hover、键盘聚焦和无 Hover 设备正确显示。
2. 加号、快捷键和 Command 打开同一“添加项目”Dialog，关闭后焦点返回。
3. 名称为空、未选类型、无根目录、默认根目录缺失、重复目录、父子目录重叠、目录失效均就地报错。
4. 连续多次选择文件夹可累积、移除和改选默认根目录；取消选择不清空表单。
5. 类型创建后不可转换，项目/笔记说明和限制在提交前可见。
6. 创建成功只声明内存成功；新项目被激活、展开会话并打开右侧文件面板。
7. 普通项目保留文件/终端/搜索/日志/调试/看板；笔记项目只显示允许的主内容、右侧和底部类型。
8. 项目切换恢复各自页签、编辑组、面板和尺寸；终端/看板与笔记面板互不串入。
9. 笔记的源码、并排、即时、预览四模式都在同一页签切换；同一笔记多编辑组共享 Buffer、独立视图。
10. Vditor 首次加载、切换、销毁、加载失败和保存失败不产生重复实例或丢失现有 Buffer。
11. 多根目录同名笔记显示上下文；Markdown 链接和 WikiLink 的唯一、歧义、未解析状态可区分。
12. 文件面板覆盖新建、重命名、移动、复制路径、废纸篓的初始/加载/成功 Mock/错误/危险确认状态。
13. 代码/纯文本只读，图片/PDF/音视频安全预览，未知或可执行文件绝不运行。
14. 大纲覆盖无标题、H1–H6、搜索、折叠、当前章节和点击定位。
15. 反向链接区分已链接/未链接，索引 partial 和失败不伪装完整。
16. 标签/属性覆盖 Front Matter 缺失、合法、未知字段和解析错误，不覆盖原文。
17. 全局/局部图谱覆盖无笔记、无链接、筛选零结果、加载、partial、错误、重试和节点列表键盘操作。
18. 图谱边只来自显式 Markdown/WikiLink，不出现 AI 推测、共同标签或相似文本关系。
19. 聊天模式拒绝所有工具；笔记代理允许根目录内任意层级/文件类型的已审批文件动作，但拒绝越界、Shell、执行、构建、调试和看板。
20. 通过符号链接、`..`、大小写或旧快照触发的越界动作被策略层拒绝并显示原因。
21. 960/1280/1440/1920 宽度无不可恢复面板和整页横向溢出。
22. 无 Card 嵌套、视觉卡片嵌套或无意义卡片墙。
