## 3. 左侧栏

左侧栏使用 shadcn/ui `Sidebar` 的 Provider、Header、Content、Group、Menu、Footer 结构，分为三个稳定区域。

### 3.1 顶部菜单区

顺序固定：

1. `Tabs`：代理 / 聊天。
2. 新建任务。
3. 知识库。
4. 应用。
5. 阅读。
6. 能力。
7. 任务。

“阅读”固定使用 Lucide `Rss` 并紧贴“应用”正下方；不在 Sidebar 展开合集子树。系统合集与自定义合集由阅读页文章列表内的合集选择器承载，避免全局 Sidebar、合集栏、文章列表和阅读窗形成四列。

#### 代理 / 聊天 Tabs

- 切换只改变新建会话与当前会话的运行能力，不切换到另一套页面。
- 当前会话有未完成代理运行时切换到聊天，使用 `AlertDialog` 说明：运行会停止，后续工具不可用。
- 聊天模式标签旁显示 `MessageCircle`；代理模式使用 `Bot`。
- 收起侧栏时 Tabs 改为两个图标 Toggle，由 Tooltip 解释。

#### 菜单选中态

- 当前管理页面使用强调背景与语义图标。
- 在聊天/文件页签工作区中，“新建任务”不因打开文件而失去会话上下文；左侧显示当前会话选中。
- 菜单 Badge 仅用于需要注意的数量，如失败任务数，不显示无意义的“0”。

### 3.2 项目与会话区

项目区位于 Sidebar Content，独立滚动；顶部菜单与底部应用菜单不随其滚动。

#### 添加项目入口

- “项目”组标题行右侧使用 `SidebarGroupAction` 放置 Lucide `Plus`。
- 默认只在项目组 Hover 时显示；加号键盘聚焦、组内 `focus-within` 或设备不支持 Hover 时必须可见。
- 入口提供 Tooltip、`aria-label="添加项目"` 和 `⌘/Ctrl+Shift+O`；快捷键与全局 Command 调用同一 Dialog。
- Dialog 使用 `Field + RadioGroup + Item` 填写名称、选择不可转换的“项目/笔记”类型、连续添加一个或多个根目录并指定唯一默认根目录。
- 名称和根目录必填；禁止重复路径、父子目录同时纳入和失效目录提交。目录选择通过未来 Adapter 调用 Wails 原生对话框，本阶段不扫描目录。
- 创建成功后设为当前项目、展开会话并打开右侧“文件”；UI Mock 只表示内存创建成功。

完整创建、校验与状态见 [16-项目与笔记工作区.md](./16-项目与笔记工作区.md) §4。

#### 项目层

- 项目组默认折叠。
- 系统固定项目“任务”始终位于第一项，不能重命名、删除或移动。
- 启动时当前上下文默认为“任务”，即使项目 disclosure 仍处于收起状态。
- 普通项目显示名称、展开箭头和状态点；HoverCard 展示路径、分支、文件数、最近活动和 Agent/MCP 状态。
- 用户项目显示不可转换的类型语义：普通项目使用通用项目图标，笔记项目使用笔记图标；不能只靠颜色区分。两类项目都保留会话层级，且都至少包含一个根目录并可包含多个根目录。
- 项目行只负责项目上下文与会话列表展开，不使用会话式选中背景；项目本身不支持归档。
- 普通项目右键提供“打开项目看板”；看板使用该项目独立的项目工作项，不复用定时任务数据。
- “打开项目看板”“新建终端”只适用于普通项目；笔记项目替换为“打开全局图谱”“新建笔记”“搜索笔记”。
- 单击项目：设为当前上下文并展开会话。
- 再次单击或点击箭头：仅切换会话列表的折叠状态。
- 项目列表支持键盘上下移动与左右展开/收起。

#### 会话层

- 每个展开项目首次展示最近 5 个会话。
- 第 6 项为“展开更多”，点击后追加 5 个；加载中用 5 行 Skeleton。
- 已全部加载后不再展示“已显示全部”或其他加载提示行。
- 会话行的 hover/选中背景与项目行等宽，Star、标题和状态保持一级缩进；相对时间移入 HoverCard，不占用标题行宽度。
- 会话行 Hover/操作按钮键盘聚焦时，在右侧显示“归档”和“更多”两个图标按钮；项目行不显示这两个按钮。
- 运行中会话使用 Spinner，等待审批使用 ShieldQuestion，失败使用 CircleAlert，临时会话使用 Timer。
- 单击会话打开；中键/修饰键单击可在应用内新页签打开会话副视图，但主“聊天”页签仍唯一。
- 搜索、归档和 Star 会影响排序：Star 在项目内置顶，其余按最近活动排序。
- 归档只作用于会话，不提供项目归档或以项目归档代替会话归档。

### 3.3 底部应用区

使用 `SidebarFooter` 展示：

- `frontend/src/assets/icons/application/icon.svg`
- 应用名称 Aestival
- 当前版本或本地状态的可选辅助文本
- `ChevronUp` 表示可展开菜单

这里不是用户头像和账户入口，不出现登录、注册、同步或个人资料。

点击后打开 `DropdownMenu`：

| 分组 | 菜单项 | 图标 |
| --- | --- | --- |
| 工作区 | 全局搜索 | `Search` |
| 工作区 | 打开设置 | `Settings` |
| 工作区 | 键盘快捷键 | `Keyboard` |
| 数据 | 打开数据目录 | `FolderOpen` |
| 数据 | 导入配置 | `Import` |
| 数据 | 导出配置 | `Download` |
| 帮助 | 文档 | `BookOpen` |
| 帮助 | 关于 Aestival | `Info` |
| 应用 | 重新加载界面 | `RefreshCw` |
| 应用 | 退出 | `LogOut` |

“退出”与其他项分组；存在未保存文件或运行中任务时使用 `AlertDialog`。

## 4. 新建任务与会话导航

### 启动路径

```mermaid
flowchart TD
  O["打开 Aestival"] --> D["当前项目 = 任务"]
  D --> N["展示新建任务页"]
  N --> I{"用户输入并发送"}
  I -->|代理模式| A["创建代理会话并运行"]
  I -->|聊天模式| C["创建纯聊天会话"]
  A --> H["会话加入任务项目"]
  C --> H
```

如果用户先选择一个项目，再新建任务，会话归入该项目。项目切换不会自动移动已存在的会话。

### 页面历史

- 标题栏后退/前进维护应用内部导航历史，不等同于会话分叉。
- 切换侧栏项目、打开设置或知识库都会进入历史。
- 打开/关闭右侧和底部面板不进入历史。
- 文件页签切换属于工作区状态，不污染页面历史。

## 5. 主内容页签

主内容顶部使用 `Tabs` 承载：

1. 固定“聊天”页签。
2. 按打开顺序排列的文件/笔记/素材预览页签。
3. 普通项目可选的应用代码页签；笔记项目可选的全局图谱单实例页签。

规则：

- “聊天”始终在首位、不可关闭、不可拖出。
- 文件双击从右侧文件树打开为持久页签；单击可先进入临时预览页签，下一次单击替换。
- 已编辑文件从临时页签自动转为持久页签。
- 脏文件显示圆点；关闭时使用保存/不保存/取消三动作 Dialog。
- 页签过多时水平滚动，右侧提供“所有页签”下拉与“关闭其他”。
- `Cmd/Ctrl+W` 关闭当前可关闭页签；当前为聊天页签时关闭窗口前先检查运行状态。
- 会话切换只替换聊天页签内容，不影响已打开文件。
- 笔记项目的 Markdown 源码、并排、即时、预览属于同一文件页签内模式；同一笔记可在多个编辑组共享 Buffer 并独立保存视图状态。

## 6. 右侧栏与底部面板导航

标题栏固定提供：

- `PanelRight`：显示/隐藏右侧栏。
- `PanelBottom`：显示/隐藏底部面板。

普通项目右侧栏标题行包含当前面板名、固定/移动按钮和更多菜单。更多菜单可选择：

- 文件
- 终端
- 搜索
- 日志
- 会话调试
- 项目看板（仅右侧栏，不允许移动到底部）

笔记项目右侧栏只允许：

- 文件。
- 搜索。
- 大纲。
- 反向链接。
- 标签与属性。
- 局部图谱。

底部面板使用多 Tabs：

- 首次展开默认创建“终端 1”。
- `+` 打开与右侧栏相同的类型选择菜单。
- 终端允许“终端 1、终端 2……”多实例。
- 其他面板已存在时，点击对应类型只聚焦，不创建重复实例。
- 面板页签可在右侧栏与底部面板之间移动。
- 普通项目看板与主内容看板共享工作项数据，但日期筛选、看板/甘特模式和选中任务分别保存；切换普通项目时两处同时切换项目，切到笔记项目时过滤看板表面。
- 关闭最后一个页签后显示 `Empty`：右侧栏提供六种面板选择（含项目看板），底部面板保持五种选择且不提供项目看板。
- 笔记项目底部面板只允许搜索与反向链接，首次展开默认搜索；终端、日志、会话调试和项目看板不会从普通项目快照串入。
- 面板、尺寸、编辑组和页签按项目保存快照；切换回原项目恢复其安全 UI 状态，不恢复终端进程或失效资源。

通用面板行为见 [09-工作区面板与文件预览.md](./09-工作区面板与文件预览.md)，双类型限制见 [16-项目与笔记工作区.md](./16-项目与笔记工作区.md) §5–§7、§11。

## 7. 管理页面统一骨架

知识库、应用、阅读设置、能力、任务和设置共享以下结构；阅读主页面使用 [15-RSS阅读与智能合集](./15-RSS阅读与智能合集.md) 定义的文章列表 + 阅读窗，不套用管理页表格骨架：

```mermaid
flowchart TB
  T["全局标题栏：当前页面名称"] --> B["Breadcrumb + 内容说明 + 主动作（按需）"]
  B --> S["指标带 / 持续 Alert（按需）"]
  S --> F["搜索 / 筛选 / 排序 / 视图切换"]
  F --> C["DataTable、列表、少量独立 Card 或详情内容"]
  C --> P["Pagination / 加载更多"]
  C -.-> D["Dialog / Sheet / Drawer 详情与编辑"]
```

统一规则：

- 页面名称只出现在全局标题栏；内容区不重复同名 `h1`，也不增加带背景或底边的整行页面 Header。
- Breadcrumb、内容说明、主动作和状态可以位于内容顶部，但必须以普通内容分区或工具栏呈现，不能形成第二条标题栏。
- 页面内只保留一个主动作。
- 宽屏使用右侧 `Sheet` 或分割详情；窄屏使用 `Drawer`。
- 筛选条件通过 Badge 可见且可逐项清除。
- 空状态说明“为什么为空”和“下一步做什么”。
- 列表与网格视图选择可记忆到本地设置。
- 管理页默认优先列表、表格、Item 和直接分区；只有独立对象的网格浏览才使用 Card。
- Card 内部不得再放 Card；详情 Sheet/Dialog 也不能靠多层卡片堆叠建立层级。

## 8. 深链接与恢复

未来路由应能表达：

- 当前顶层页面。
- 当前能力中心 Tab。
- 当前设置分类。
- 当前项目与会话。
- 当前项目类型、根目录安全定位、笔记页签和图谱查询；路由不保存绝对路径、正文或图谱布局对象。
- 当前知识库/数据连接/外部消息连接/应用/任务详情；外部消息连接的深链接只保存安全定位信息，不包含凭据、配对码或消息正文。
- 当前阅读合集、当前文章的安全定位，以及设置中的阅读页签；路由不包含文章正文、远程模型请求或临时 OPML 内容。

右侧栏、底部面板、分割比例、最近页签属于本地工作区状态，不要求进入 URL。应用重启后：

- 恢复最后页面与面板布局。
- 恢复当前项目自己的类型兼容页签、编辑组、面板和尺寸；过滤另一类型的非法面板。
- 有敏感或临时内容时不自动恢复正文，只恢复安全的定位信息。
- 上次处于临时会话时，默认回到新建任务并提示可从恢复记录找回。
- 上次阅读文章已不存在或合集已删除时回到“全部”，保留可恢复的列表筛选并说明回退原因。
