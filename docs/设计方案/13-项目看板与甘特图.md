# 项目看板与甘特图

## 1. 范围与领域边界

项目看板管理“项目工作项”，与左侧顶层“任务”页面中的定时任务完全分离。每个普通项目（包括固定“任务”项目）拥有独立工作项集合；笔记项目按 [16-项目与笔记工作区.md](./16-项目与笔记工作区.md) 不提供项目看板、甘特图或项目工作项动作。首版仅实现前端内存 Mock、权限策略和未来服务接口，不执行真实 AI 规划，也不持久化到本地文件或后端。

主状态固定为：待处理、处理中、受阻、待验收、已完成。作废属于 lifecycle，不增加第六列。

## 2. 入口与项目上下文

- 标题栏搜索按钮后使用 `SquareKanban` 图标。点击后主内容全屏显示当前项目看板，标题栏唯一显示“项目名 · 看板”。
- 主看板工具栏提供“在右侧打开”。右侧面板 `+` 菜单也提供“项目看板”。
- 项目右键菜单提供“打开项目看板”。单击项目或打开该项目会话时同步 `activeProjectId`。
- 上述入口只在普通项目与固定“任务”项目中显示；笔记项目隐藏入口，Command、快捷键、旧快照或代理命令触发时也由策略层拒绝。
- 主看板与右侧看板共享工作项和审计事件；日期范围、看板/甘特模式、紧凑状态与选中任务互不影响。
- 看板面板仅允许位于右侧栏，不允许移动到底部面板。

## 3. 看板视图

主看板使用一个水平/垂直可滚动画布，五列标题吸顶，每列是普通 Section；每个任务是单层 `Card`，禁止 Card 套 Card。任务卡展示编号、标题、优先级、标签、计划日期、最近操作者，以及受阻/待验收等必要提示。

拖放使用 DnD Kit：

- 支持列内排序、跨列移动、空列放置、`DragOverlay` 与键盘拖放。
- 进入“已完成”不直接提交移动，而是弹出人工“验收并完成”确认。
- 普通人类移动采用乐观反馈和撤销 Toast；服务拒绝时回滚。
- 已完成任务由人类拖出时记录为重新打开；AI 不具备该权限。

右侧面板按容器宽度响应：宽度不小于 640px 时显示多列画布；更窄时显示状态选择器和单列任务，并继续支持状态移动。

## 4. 筛选、创建与详情

日期筛选默认“本月 + 包含未排期”，提供本周、未来 7 天、未来 14 天、本月与自定义范围。任务的计划起止日期与筛选范围有交集即显示；未排期和已作废分别由独立 Switch 控制。

工具栏包含：看板/甘特切换、日期范围、未排期/作废开关、创建任务、AI 规划 Mock，以及主表面的“在右侧打开”。

任务详情包含说明、状态、优先级、标签、计划日期、受阻原因、验收标准和最近审计事件：

- 主看板使用右侧 `Sheet`。
- 右侧看板使用 `Dialog`，避免再次嵌套 Sheet。
- 已完成和已作废任务默认只读，分别提供重新打开或恢复入口。
- 作废要求填写原因并经过 `AlertDialog`；恢复回到作废前状态。

## 5. 甘特图

甘特图左侧固定任务信息，右侧按天绘制时间轴，展示今日线、周末底色、任务计划条和状态颜色。计划条覆盖 `plannedStart` 至 `plannedEnd`（含边界），点击打开同一详情；未排期任务单独分组。

首版只读：不支持拖动改期、拉伸工期、依赖箭头、关键路径和资源负载。日期只在任务详情中修改。

## 6. 权限与审计

所有修改必须提交 `ProjectBoardCommand`，组件不得直接改状态：

| 动作 | 人类 | AI |
| --- | --- | --- |
| 创建、编辑、排序、前四状态间移动 | 允许 | 允许 |
| 待验收 → 已完成 | 允许，必须确认 | 拒绝并记录 |
| 已完成 → 前四状态 | 允许 | 拒绝 |
| 作废、恢复 | 允许，作废需原因 | 拒绝 |

创建、编辑、排序、状态变更、验收、重新打开、作废、恢复和策略拒绝均生成 `ProjectWorkItemEvent`。首版事件保存在内存中，并明确标记为前端 Mock。

## 7. 状态与服务边界

- `ProjectWorkItem`：项目归属、五状态、lifecycle、优先级、标签、日期、验收标准、排序和操作者。
- `ProjectBoardSurfaceState`：主/右表面的视图、范围、开关、紧凑状态与选中任务。
- `ProjectBoardService`：查询快照、提交命令和订阅变化。
- `ProjectBoardPlanningAdapter`：未来允许 AI 读取快照并提交受相同策略约束的命令。

Zustand 保存业务快照与 UI 表面状态；未来 Wails 服务替换内存 Adapter 时不修改展示组件。AI 规划按钮当前只生成/调整 Mock 工作项，不声称真实模型已完成规划。

## 8. 响应式与验收

- 960×640、1280×800、1440×900、1920×1080 以及主/右看板同时打开时无页面横向溢出。
- 主看板只有一个主要画布滚动容器；列本身不建立独立滚动区。
- 任务卡、菜单、详情、日期选择、创建与拖放支持键盘和可见焦点。
- 每个普通项目任务集合互相隔离；切换普通项目时双表面同步项目但不串筛选，切到笔记项目时关闭/过滤看板表面并保留原普通项目安全快照。
- 权限策略、日期交集、未排期、作废、排序和恢复有纯状态测试。
- TypeScript、Vite production build 与 `git diff --check` 通过。
