# 任务与设置

## 1. 定时任务

### 1.1 页面结构

任务页使用 Tabs：

- 任务
- 日历
- 运行记录

头部主动作“创建任务”。其下默认使用 `Item + Separator` 的指标带：

- 已启用任务。
- 今日将运行。
- 等待审批。
- 最近失败。

### 1.2 任务列表

DataTable 列：

| 列 | 内容 |
| --- | --- |
| 名称 | 图标、名称、说明 |
| 执行内容 | 智能体/会话/工作流/Prompt |
| 计划 | 人类可读的时间 + Cron 摘要 |
| 下次运行 | 绝对时间 + 相对时间 |
| 最近结果 | 成功、失败、跳过、等待审批 |
| 状态 | 启用 Switch |
| 动作 | 立即运行、更多 |

筛选：

- 状态。
- 触发类型。
- 智能体/项目。
- 最近结果。
- 日期范围。

右键菜单：

- 立即运行。
- 查看详情。
- 编辑。
- 复制一份。
- 暂停/启用。
- 查看运行记录。
- 导出。
- 删除。

### 1.3 创建任务

使用分步 Dialog/Sheet。

#### 第一步：基本信息

- 名称。
- 说明。
- 所属项目。
- 标签。
- 启用状态。

#### 第二步：执行内容

RadioGroup：

- 运行一段 Prompt。
- 继续指定会话。
- 运行智能体。
- 触发工作流。

配置：

- 模型/智能体。
- 指令。
- Skill。
- 知识库。
- 输入附件。
- 工作目录。

继续会话时显示当前上下文大小、是否允许自动压缩与“会话被删除时”的处理方式。

#### 第三步：触发时间

使用 Tabs：

- 简单计划。
- Cron 表达式。

简单计划支持：

- 仅一次：`Calendar + DatePicker + 时间 Select`。
- 每隔：分钟/小时/天/周/月。
- 每天指定时间。
- 每周指定星期和时间。
- 每月指定日期与时间。

Cron：

- Input 输入表达式。
- 实时语法校验。
- 人类可读说明。
- 接下来 5 次运行时间。
- 常用模板 Combobox。
- 明确时区。

时区默认采用系统时区；当前环境为 `Asia/Shanghai` 时，预览同时显示 `UTC+08:00`，避免夏令时歧义。

#### 第四步：运行策略

- 最大运行时长。
- 失败重试次数与退避。
- 上一次未完成时：跳过、排队、并行。
- 错过运行时：跳过、下次启动补跑、立即补跑。
- 上下文压缩。
- 最大费用/Token guardrail。

审批策略：

- 计划任务不能弹出阻塞整个应用的系统原生确认。
- “请求审批”会让任务暂停并发送通知，用户从任务中心继续。
- “自动审批”只能在预先授予的工具、路径和域名范围内执行。
- “绕过审批”创建时必须显示高风险 AlertDialog，且任务列表持续显示风险 Badge。

#### 第五步：通知与确认

- 开始时。
- 成功时。
- 失败时。
- 等待审批时。
- 超过费用/时长阈值时。

确认页展示执行摘要、权限、接下来 5 次时间和预计成本。

### 1.4 日历

- 月/周/日 ToggleGroup。
- 使用 Calendar 展示计划运行点。

### 1.5 运行记录

- 任务。

- 持续时间。
- 模型。
- Token/费用。
- 工具调用数。
- 结果。
- 日志/会话。

详情 Sheet 使用 Tabs：

- 摘要。
- 输出。
- 工具。
- 日志。
- 费用。

支持从失败运行重试、从该次结果创建会话、导出脱敏记录。

### 1.6 状态

| 状态 | 表达 |
| --- | --- |
| 已启用 | 正常状态，显示下次运行 |
| 已暂停 | Pause Badge，无下次运行 |

## 5. 连接

### 5.1 定位与边界

“连接”用于把 Aestival 作为本地 Agent 网关接入外部消息平台，让用户能够从已授权的私聊、群组、频道或话题中发起对话、创建代理任务、查看状态并接收结果。

它与另外两类“连接”严格区分：

- 不是 Aestival 登录、注册或云账户；连接某个平台只是在本机保存一个机器人/应用/连接器配置。
- 不是知识库中的“数据连接”；数据库、向量库和文件来源仍由知识库页面管理。
- 不是通知渠道的同义词；通知只负责推送事件，外部消息连接同时处理入站消息、会话路由、命令、回复和附件。

通用边界：

- 支持 Telegram、飞书、Discord、钉钉、微信和 QQ 六类设计目标。
- 同一平台可添加多个账号、机器人或应用实例，每个实例必须有唯一别名。
- Aestival 或其明确启用的本地后台服务必须处于运行状态，外部消息才会被接收；本轮不假设存在 Aestival 云中继。
- 每条入站消息必须先通过平台认证、发送者/群组访问策略和路由规则，才可进入会话。
- 外部渠道可以进入聊天模式或代理模式，但不能绕过 [代理与聊天](./04-代理与聊天.md) 的能力边界和审批引擎。
- 渠道凭据、扫码会话和原始 Authorization 不进入普通 Zustand 持久化，也不出现在导出和诊断日志中。

### 5.2 页面结构

连接页使用 Tabs：

- 连接。
- 配对请求。
- 活动记录。

页面头部主动作是“新建连接”。连接 Tab 顶部使用 `Item + Separator` 指标带，不使用统计 Card：

- 已启用连接。
- 当前在线。
- 待处理配对。
- 需要处理。

工具栏：

- `Command` 搜索别名、平台和机器人/应用名称。
- 平台 Combobox。
- 状态 Select。
- 路由项目/智能体筛选。
- “仅显示有风险”Toggle。

连接列表默认使用 DataTable：

| 列 | 内容 |
| --- | --- |
| 连接 | 平台图标、实例别名、机器人/应用显示名 |
| 接收范围 | 私聊、群组、频道、话题及提及规则摘要 |
| 默认路由 | 项目、智能体、聊天/代理模式 |
| 权限 | 配对/允许列表、远程审批和风险 Badge |
| 传输 | 轮询、WebSocket、Stream、Webhook 或连接器报告的实际方式 |
| 状态 | 在线、连接中、受限、需认证、错误、已暂停 |
| 最近活动 | 最近入站/出站时间，不显示消息正文 |
| 动作 | 测试、暂停/恢复、更多 |

每一行的更多菜单和右键菜单按能力裁剪：

- 查看详情。
- 测试连接。
- 查看配对请求。
- 编辑访问策略。
- 编辑路由与权限。
- 暂停接收/恢复。
- 立即重连。
- 复制脱敏诊断。
- 导出脱敏配置。
- 断开并删除。

断开并删除必须使用 `AlertDialog`，明确正在运行的会话不会被删除，但该连接将停止收发且未投递队列会按用户选择“保留待恢复”或“取消投递”。

### 5.3 渠道差异

渠道选择使用 `Item` 网格或紧凑列表，不把六个平台做成嵌套 Card。每项显示“接入身份、可用会话类型、连接方式、能力成熟度”。

交互基线参考 [OpenClaw 聊天渠道](https://docs.openclaw.ai/zh-CN/channels) 和 [渠道配置](https://docs.openclaw.ai/gateway/config-channels) 中的 Gateway、多账号、私聊配对/允许列表、群组提及门控和按来源路由思路；Aestival 不承诺配置文件或插件 API 与 OpenClaw 兼容，各渠道仍以自身官方 API、经验证的连接器和运行时能力探测为准。

| 渠道 | 首选接入身份与方式 | 对话范围 | 配置与风险提示 |
| --- | --- | --- | --- |
| Telegram | Bot Token；长轮询优先，可选 Webhook | 私聊、群组、话题 | 默认私聊配对；群组默认允许列表并要求提及；Webhook 需要可验证回调地址 |
| 飞书 | 企业自建应用/机器人；App ID + App Secret 或受支持的扫码创建流程；WebSocket 优先，可选 Webhook | 私聊、群聊、话题/卡片能力按探测结果 | 区分飞书与 Lark 域名；展示租户、事件订阅和应用权限；缺少权限时不宣称连接完整 |
| Discord | Developer Application + Bot Token；Gateway 连接 | 私信、服务器、频道、线程 | 检查 Message Content 等必要 Intent、邀请范围和 Bot 权限；机器人消息默认忽略以防循环 |
| 钉钉 | 企业内部应用/机器人；AppKey + AppSecret 或经验证的官方连接器；Stream 优先，可选回调 | 单聊、群聊及卡片能力按应用授权与探测结果 | 展示企业/组织归属、机器人发布状态与权限范围；自定义 Webhook 只提供单向发送时不能标记为“可交互” |
| 微信 | 经验证的微信连接器扫码配对；连接器能力与来源必须可见 | 初始按私聊设计；群聊仅在连接器明确报告支持且用户单独启用时出现 | 标记“外部连接器/实验性”或实际来源；展示登录有效期、平台限制与合规提示；不得把未知个人号自动化能力伪装成官方稳定能力 |
| QQ | QQ Bot AppID + AppSecret，或受支持的扫码绑定；官方 Bot 网关 | 私聊、群聊、富媒体能力按探测结果 | 使用 OpenID/群 ID 等稳定标识配置允许列表；群聊默认要求提及；凭据失效时进入“需认证” |

规则：

- 上表定义 UI 需要承载的配置方向，不代表六个平台已经完成真实集成。
- 文本是最低共同能力；图片、文件、语音、回复引用、编辑、表情回应、流式更新和主动推送都以测试后的能力探测结果为准。
- 连接详情使用能力 Badge 明确“可用、受限、不支持、待验证”，不能因为平台理论支持就提前点亮。
- 连接器来源显示“内置、平台官方、Aestival 官方、外部”之一；外部连接器同时显示版本、签名/校验状态、维护者和权限范围。

### 5.4 新建连接向导

使用宽 `Dialog` 或 `Sheet`；窄窗口改为 `Drawer`。向导保留草稿但不持久化明文 Secret。

#### 第一步：选择渠道

- 选择 Telegram、飞书、Discord、钉钉、微信或 QQ。
- 显示该渠道的接入前置条件、支持范围和已知限制。
- 若所需适配器未安装，显示“尚不可用”和依赖说明；当前只做 UI 时必须明确标记 Mock，不模拟安装成功。

#### 第二步：身份与连接

通用字段：

- 实例别名。
- 机器人/应用身份。
- 连接方式。
- 平台区域或 API 域名。
- 网络代理、超时、重试和证书放入 Accordion。

凭据交互：

- Bot Token、App Secret 等使用 `InputGroup` 的密码输入，默认遮挡。
- 支持引用系统安全存储、环境变量或受限文件；只展示引用名和末尾指纹，不显示完整值。
- 扫码配对使用有可访问标题的 Dialog；二维码旁提供短时文本码/状态说明，过期后明确刷新。
- 平台扫码只授权该外部渠道，不得出现“Aestival 登录成功”等文案。
- 凭据写入本地安全存储前展示存储位置类型和撤销方式。

#### 第三步：访问范围

私聊策略使用 `RadioGroup`：

| 策略 | 行为 |
| --- | --- |
| 配对（默认） | 未知发送者只收到短时配对码；必须在本机连接页批准后才能继续 |
| 允许列表 | 只有明确列出的稳定用户 ID 可发起会话 |
| 禁用 | 忽略所有私聊入站 |
| 开放 | 位于高级设置；任何人都可发起，必须通过高风险 `AlertDialog` |

“开放”只允许绑定聊天模式，或绑定一个所有副作用工具均禁用的受限代理配置；连接行持续显示风险 Badge。

群组/频道策略：

- 默认禁用；启用后默认“允许列表 + 必须提及机器人”。
- 可配置允许的服务器/租户/群组/频道/话题和发送者角色/用户。
- 每个群组可以覆盖“是否要求提及、历史上下文条数、允许命令、默认智能体”。
- 未经允许的群消息不进入模型上下文；不能仅隐藏回复但仍偷偷采集正文。
- 机器人、自身回声和重复事件默认忽略；显式允许机器人互聊时必须开启循环次数与频率限制。

配对码有短时有效期、剩余时间和尝试次数限制。配对批准只授予当前平台、连接实例和发送者作用域，不自动获得其他群组、连接或管理员权限。

#### 第四步：会话与路由

配置：

- 默认项目。
- 默认模式：聊天（默认）或代理。
- 默认智能体和模型；未选择时继承项目默认。
- 会话隔离：按连接实例 + 会话/频道 + 发送者 + 话题/线程生成稳定作用域。
- 私聊默认“每个发送者独立会话”；群聊默认“每个群组/频道与话题独立会话”。
- 是否允许外部发送者创建新会话、继续当前会话或只向固定会话发送。
- 空闲多久后开始新会话，以及是否允许外部 `/new` 主动开始。

入站会话在 Aestival 中显示平台、连接别名和来源会话 Badge；用户可以把它移动到其他项目，但不能因此扩大连接访问权限。

首批通用控制命令：

| 命令 | 行为 | 权限 |
| --- | --- | --- |
| `/new` | 在当前来源作用域创建新会话 | 已配对/允许的发送者 |
| `/status` | 查看当前运行、队列和等待审批摘要 | 已配对/允许的发送者 |
| `/stop` | 停止由当前来源发起且仍在运行的任务 | 任务发起者或连接所有者 |
| `/help` | 展示该连接实际可用的命令 | 所有已获准发送者 |

平台原生命令、按钮或卡片只是同一命令的不同表现，不创建绕过权限的新入口。管理连接、修改允许列表、切换绕过审批、读取诊断和删除数据不提供远程命令。

#### 第五步：代理权限与回复

代理模式必须绑定一个明确的远程权限配置：

- 允许的工具、MCP、Skill、工作流。
- 可访问的工作目录、文件路径和域名。
- 最大单次运行时长、Token/费用、并发和频率。
- 是否允许附件落盘；默认只作为受限输入解析。
- 等待审批超时后的行为：保持等待、拒绝并继续或取消任务。

审批：

- 默认只能在 Aestival 桌面端处理工具审批。
- 可选“允许连接所有者远程批准低/中风险动作一次”；必须先把平台稳定身份标记为连接所有者，并通过 `AlertDialog` 启用。
- 远程审批必须引用具体运行和动作、短时有效、一次性使用，并把决定写入脱敏审计。
- 永久项目授权、绕过审批、删除/覆盖、任意命令、扩大路径/域名范围等高风险决定始终只能在桌面端完成。
- 远程发送者不能修改当前审批策略；其请求继续遵循会话、项目和全局策略的最严格交集。

回复：

- 默认回复到原平台、原账号和原私聊/群组/频道/话题，不跨渠道广播。
- 长文本按平台限制安全分段；保留段序和引用关系。
- 支持平台原生流式/卡片更新时可以启用，否则使用“处理中”状态后发送最终结果。
- Markdown、代码、图片、文件、语音和表情回应按能力矩阵降级；降级前预览最终表现。
- 主动发送到新的目标属于单独权限，不能因接收过一次消息就自动获得广播能力。

#### 第六步：测试与确认

测试使用 `Progress` 展示：

1. 凭据与连接器校验。
2. 网络与长连接/Webhook/Stream 可用性。
3. 接收事件权限。
4. 发送消息权限。
5. 私聊、群组、媒体和流式能力探测。
6. 回声、重复事件和循环保护检查。

测试规则：

- 默认只调用平台自检接口，不向模型发送消息、不运行工具。
- 需要真实收发时，用户必须选择测试目标并确认；测试消息带“Aestival 连接测试”标识。
- 失败 Alert 给出发生阶段、影响和恢复动作；复制诊断时脱敏 Token、Secret、用户/群组标识和消息正文。
- 确认页展示连接身份、访问范围、默认路由、代理权限、远程审批、数据存储和平台限制。

### 5.5 连接详情

详情使用 Tabs：

- 概览：身份、连接器、传输、状态、最近活动。
- 访问：私聊/群组策略、允许列表、配对记录。
- 路由：项目、智能体、会话隔离、命令。
- 权限：代理范围、审批与费用/时长限制。
- 能力：文本、媒体、回复、流式、主动发送的探测结果。
- 诊断：分步测试、重连历史、脱敏错误。
- 活动：入站/出站元数据、路由结果和投递状态。

概览和详情使用普通 Section、`Item`、`Separator`、`Table`、`Accordion` 和 `Alert`，不把每个字段组做成 Card。

状态模型：

| 状态 | UI 表达 | 主要动作 |
| --- | --- | --- |
| 未配置 | Empty/Muted Badge | 继续配置 |
| 测试中 | Progress | 取消测试 |
| 连接中 | Spinner | 查看阶段 |
| 在线 | CheckCircle + 最近心跳 | 测试/暂停 |
| 受限 | Alert + 能力 Badge | 补权限/接受降级 |
| 重连中 | Spinner + 重试次数 | 立即重试/暂停 |
| 需认证 | KeyRound Alert | 更新凭据/重新扫码 |
| 错误 | CircleAlert + 错误阶段 | 复制诊断/重试 |
| 已暂停 | Pause Badge | 恢复 |
| 已禁用 | Muted Badge | 编辑/启用 |

“在线”只表示渠道传输健康，不代表模型、工具或目标项目可用；详情应分别显示渠道、路由目标和代理运行依赖的状态。

### 5.6 配对请求

配对请求使用 DataTable：

| 列 | 内容 |
| --- | --- |
| 请求者 | 平台显示名 + 脱敏稳定 ID |
| 来源 | 连接别名、私聊/群组/频道 |
| 配对码 | 默认遮挡，可按需核对 |
| 请求时间 | 绝对时间 + 剩余有效期 |
| 风险 | 新账号、未知群组、频率异常等 Badge |
| 动作 | 批准、拒绝 |

批准 Dialog 必须展示实际授予范围：

- 仅当前连接实例。
- 私聊或指定群组/频道。
- 可使用的聊天/代理模式。
- 是否标记为连接所有者。
- 到期策略或永久允许列表项。

默认批准普通发送者，不自动标记为所有者。批量操作只支持“全部拒绝/清除过期”，不支持批量批准未知发送者。

### 5.7 活动记录与诊断

活动记录只保存完成排障和审计所需的最小元数据：

- 时间、方向、平台事件 ID 的脱敏指纹。
- 连接、来源作用域和目标会话。
- 访问策略结果、路由结果。
- 投递、重试、去重、限流和失败状态。
- 附件类型与大小，不默认保存正文或文件内容。
- 触发的代理运行 ID、审批状态和最终结果摘要。

默认不展示完整消息正文。用户从对应会话查看正文；导出活动记录前显示脱敏预览。支持按连接、方向、结果、时间和运行 ID 筛选。

需要持续可见的诊断：

- 本地后台服务未运行。
- 网络离线或平台不可达。
- Webhook 地址不可访问/签名校验失败。
- 长连接反复重连。
- 凭据过期或权限被撤销。
- 目标项目、智能体或模型不可用。
- 队列积压、平台限流或消息过长。

### 5.8 安全、隐私与可靠性

- 默认拒绝：私聊默认配对，群组默认禁用；启用群组后使用允许列表并要求提及。
- 最小权限：平台权限、Aestival 工具权限、文件/域名范围和主动发送范围分别配置，最终采用最严格交集。
- 本地凭据：Secret 进入系统安全存储或明确的 Secret 引用；普通设置、Zustand、日志、剪贴板预览和导出不得含明文。
- 稳定身份：访问控制使用平台稳定 ID，不依赖可改名的昵称、群名或用户名。
- 会话隔离：不同平台、连接实例、发送者、群组和话题不能错误复用上下文。
- 去重与顺序：使用平台事件 ID 去重；同一来源按序处理，重连后允许安全重放但不能重复执行有副作用工具。
- 循环保护：默认忽略机器人和自身消息；主动允许时限制连续自动回复次数、频率和总成本。
- 附件安全：限制大小、类型和数量；可执行文件与未知格式只作为不可执行附件，落盘和打开仍受审批。
- 远程审批：只允许已标记的连接所有者处理明确开放的一次性审批；高风险决策留在桌面端。
- 停止开关：设置页和应用全局状态均提供“暂停所有外部连接”，恢复时逐个确认异常队列。
- 数据最小化：群聊未提及消息默认不采集；诊断和活动记录不默认复制正文。
- 真实状态：UI 原型不得伪造连接、扫码、消息收发或远程任务成功。

### 5.9 响应式、无障碍与页面状态

- 960px 窄窗口下，分类栏进入 Sheet；连接 DataTable 降级为 `Item` 列表，主状态、平台、路由和风险仍可见。
- 二维码有可读说明、倒计时和文本替代步骤；不只依赖扫码图像。
- 状态不能只靠颜色，必须同时使用 Lucide 图标、Badge 文本和必要的 Alert。
- 纯图标动作具有 `aria-label` 和 Tooltip；暂停、重连、批准、拒绝均可通过键盘完成。
- Field 校验同时设置 `data-invalid` 与 `aria-invalid`；关闭向导后焦点返回原触发项。

页面至少覆盖：

| 页面状态 | 表达 |
| --- | --- |
| 无连接 | `Empty`：说明外部消息用途，唯一主动作“新建连接” |
| 适配器不可用 | `Alert`：缺失项、来源和可执行下一步 |
| 加载 | 与列表/详情结构一致的 Skeleton |
| 部分在线 | 保留健康连接可用，问题连接逐行显示 |
| 离线 | 本地配置仍可编辑，测试/收发动作解释禁用原因 |
| 待配对 | Tabs 计数 Badge + 本地通知 |
| 凭据过期 | 持续 Alert + “更新凭据/重新扫码” |
| 平台限流 | 显示恢复时间、队列和是否继续接收 |
| 权限不足 | 指出平台权限或 Aestival 权限，不笼统显示“失败” |
| 成功 | Sonner + 定位到连接详情，不伪造真实平台消息 |

## 6. 阅读

阅读设置是订阅源与合集的唯一完整管理面；阅读主页面只保留“添加订阅”“管理阅读”等快捷入口。详细页面、状态、安全和验收规范以 [15-RSS阅读与智能合集](./15-RSS阅读与智能合集.md) 为准。

阅读分类使用四个 `Tabs`：

| 页签 | 核心内容 | 主要组件 |
| --- | --- | --- |
| 订阅源 | 公开 RSS/Atom/JSON Feed 添加、候选预览、状态、刷新、暂停、合集分配、取消订阅与 OPML | DataTable/Item、Dialog、Field、Progress、AlertDialog |
| 合集 | 固定系统合集、两类自定义合集、创建/编辑/重排/删除、匹配预览 | Tabs、DataTable/Item、Dialog、Combobox、Textarea |
| AI 与精选 | 阅读全局模型、精选要求、远程授权、分类队列、反馈规则与显式重跑 | Select/Combobox、Textarea、Alert、Table、Dialog |
| 阅读偏好 | 默认打开方式、已读触发、未读数字 | RadioGroup/Select、Switch、Item |

### 6.1 订阅源

- 接受网站 URL 或 Feed URL，添加前显示发现到的公开 Feed 候选；多候选必须由用户选择。
- 订阅源覆盖草稿、验证中、活跃、暂停、受限、错误状态，错误需区分网络、格式、解析和安全拦截。
- 支持重命名、暂停/恢复、立即刷新、分配多个来源合集、复制地址、打开网站和取消订阅。
- 取消订阅使用 `AlertDialog`，默认停止更新并保留历史，也可选择同时删除历史文章及其已读、收藏和合集记录。
- OPML 导入先预览，再按“新增、重复合并、无效、不支持”逐项处理；部分失败保留成功项。
- 标准 OPML 只导入/导出 Feed 与来源合集；AI 合集、精选要求和反馈规则由 Aestival 配置导出承载，凭据不进入任何普通导出。
- 私有鉴权 Feed、网页转 Feed 与网页全文提取不在首版。

### 6.2 合集

- 系统合集只有“精选”和“全部”，不可重命名、删除或重排。
- 自定义合集创建第一步必须在“订阅源合集”和“AI 合集”之间二选一；保存后类型不可转换。
- 来源合集选择一个或多个 Feed，并包含这些来源的全部文章；一个来源可进入多个来源合集。
- AI 合集不选择来源，以自然语言要求分析全部活跃订阅的新文章；创建可回溯新文章、7/30/90 天或全部，默认 30 天，并在保存前预览匹配。
- 一篇文章可以同时属于多个来源合集和多个 AI 合集；删除合集不删除文章或订阅源。
- 所有合集按发布时间倒序，AI 不重排；相似或重复报道逐篇保留。

### 6.3 AI 与精选

- 阅读使用独立的全局默认模型；单个 AI 合集可覆盖，精选使用全局阅读模型。
- 精选综合可信度、证据丰富度、信息密度、原创性、新鲜度和用户相关性，并明确标注这是模型判断而非事实保证。
- 远程模型首次用于阅读前必须披露会发送文章正文/摘要、元数据、用户要求和当前合集反馈规则，并明确不发送 Feed 凭据；用户取消时不得发送。
- 精选和 AI 合集的命中文章显示入选理由，不展示伪精确置信分数或内部思维链。
- “更符合/不符合”只为当前精选或 AI 合集创建可查看、可撤销规则；不根据阅读、收藏、跳过或停留暗中学习，也不静默改写文字要求。
- 修改模型、文字要求或规则后不自动重跑全部历史；用户显式选择只处理新文章或重跑范围。

### 6.4 阅读偏好

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 默认打开方式 | 列表 + 阅读窗 / 整页阅读 / 直接打开原网页 | 列表 + 阅读窗 |
| 标记已读 | 打开时 / 滚动到底 / 仅手动 | 打开时 |
| 未读数字 | 显示 / 隐藏 | 显示 |

设置即时作用于后续阅读行为，不追溯改写历史。每篇文章的操作菜单仍可临时选择另外两种打开方式。

### 6.5 状态与 Mock 边界

- 覆盖无订阅、无文章、验证中、多候选、重复、OPML 部分失败、源暂停/受限/错误、离线和取消订阅确认。
- 覆盖模型未配置、远程未授权、排队、分析、命中、不命中、失败与零匹配。
- UI Mock 不得声称真实发现/刷新 Feed、读写 OPML、导出配置或完成模型分类。
- 未来抓取器需单独设计并防范不受信任 URL、重定向、内网访问、超大响应、恶意 XML/JSON 和不安全 HTML。

## 7. 通知

通知渠道：

- 应用内。
- 系统通知。
- 声音。

事件：

- 代理完成。
- 请求审批。
- 代理/工具失败。
- 定时任务开始/成功/失败。
- 模型不可用或限流。
- 费用/Token 阈值。
- MCP/Skill 更新。
- 新的外部渠道配对请求。
- 外部消息连接需认证、持续离线、重连失败或消息投递失败。
- 应用运行错误。

设置：

- 每个事件独立渠道。
- 勿扰时段。
- 应用位于前台时是否发系统通知。
- 是否在通知中展示消息内容。
- 声音选择与试听。
- 系统权限状态与“打开系统设置”。

通知中心使用 Popover/Sheet；支持全部已读、单条删除、跳转目标。敏感会话默认只显示“任务需要处理”，不展示正文。

## 10. 关于

关于页以普通 Section、Item 和 Separator 分段；顶部品牌摘要允许使用一张独立 Card：

- `logo.svg`。
- Aestival 名称与版本。
- Wails、前端运行时和操作系统信息。
- 更新状态与检查更新。
- 许可证与第三方许可证。
- 官网/文档/问题反馈链接。
- 数据目录、日志目录、配置目录。
- “复制诊断信息”。

诊断信息预览后复制，默认脱敏用户名、绝对路径、Token、Endpoint 查询参数和会话内容。

危险/维护操作单独分组：

- 打开日志目录。
- 重建搜索索引。
- 清理缓存。
- 恢复默认设置。

清理缓存与恢复默认设置使用 AlertDialog，并明确不删除会话/项目或会删除哪些内容。
