# Office 与 PDF 文档预览

## 1. 目标与边界

文档预览属于编辑工作台的一种编辑器输入。用户从右侧文件树打开文档时，文件进入当前获得焦点的编辑组；文档不会直接塞入狭窄的文件面板，也不会改写其他编辑组的活动页签。

首版采用“真实样例 + 本地产物”的前端 Mock：

- PDF 在浏览器中由 PDF.js 解析真实文件。
- Word 使用开发期 LibreOffice 生成的本地 PDF 预览产物；PowerPoint 优先使用 PowerPoint/Keynote 原生导出的本地 PDF，避免转换环境缺失中文字体时发生字形丢失，无法提供保真产物时才使用 LibreOffice 并显式校验结果。
- Excel 使用开发期提取的安全工作簿 JSON 显示只读网格，并提供 PDF 打印预览。
- 不接入 Wails 文件读取、运行时 Office 转换、外部在线预览服务或 Office 编辑能力。

每个文件在编辑组中只保留一个页签。缩略图、目录、源码/预览、网格/打印等都是同一页签内的显示模式，不创建第二级文件页签。

## 2. 数据描述与适配层

统一描述对象只保存可公开的资源 URL 和安全元数据：

```ts
type DocumentPreviewDescriptor =
  | { kind: "pdf"; sourceUrl: string }
  | { kind: "word"; sourceUrl: string; previewPdfUrl: string }
  | {
      kind: "presentation"
      sourceUrl: string
      previewPdfUrl: string
      slides: Array<{ index: number; title?: string }>
    }
  | {
      kind: "spreadsheet"
      sourceUrl: string
      workbookManifestUrl: string
      printPdfUrl: string
    }
```

`DocumentPreviewAdapter` 负责按文件 ID 返回描述对象和工作簿清单。当前 `MemoryDocumentPreviewAdapter` 从 Mock 文件表读取；未来 Wails Adapter 必须保持同一接口，展示组件不得直接调用文件运行时。

预览 UI 状态以 `editorId` 为键，而不是只以 `fileId` 为键：

- 当前页、缩放比例和适配模式。
- 导航栏展开状态以及缩略图/目录模式。
- PPT 当前幻灯片和放映状态。
- Excel 当前工作表、活动单元格和网格/打印模式。

因此同一文档可同时在两个编辑组中停留在不同页码和比例。PDF 对象、Canvas、TextLayer、Office 二进制和生成 HTML 不进入 Zustand；编辑器关闭或临时预览被替换时清理对应状态。

## 3. 预览产物

开发期脚本 `frontend/scripts/generate-document-preview-fixtures.py` 只用于生成仓库内样例产物：

1. LibreOffice headless 将 Word 和 Excel 转为 PDF；PPT 可通过 `--presentation-preview` 接收 PowerPoint/Keynote 原生导出的保真 PDF，未提供时才由 LibreOffice 转换。
2. `openpyxl` 提取工作表、显示值、公式、合并单元格、行列尺寸和基础样式。
3. `python-pptx` 提取幻灯片编号和标题。
4. `pypdf` 校验页数和目录。
5. 结果写入 `frontend/src/assets/document/previews/manifest.json`，应用构建不依赖本机 LibreOffice 或 Python。

样例事实：

| 文件 | 预览结果 |
| --- | --- |
| `pdf测试.pdf` | 17 页，包含可跳转的嵌套 Outline |
| `word测试.docx` | 19 页 PDF，包含源文档定义的多级目录 |
| `测试ppt.pptx` | 8 张幻灯片，标题清单与 PDF 页一致 |
| `测试excel.xlsx` | 2 个工作表，4 页打印预览，第二个工作表包含图表 |

未登记本地产物的 Office 文件必须显示“暂无本地预览产物”，不能伪造成功或访问外部服务。

## 4. 统一预览框架

`DocumentPreviewShell` 的视觉结构固定为：

`文档工具栏 → 可折叠导航区 + 内容区 → 文档状态栏`

工具栏按格式显示：

- 导航栏开关。
- 当前页/总页数或幻灯片编号。
- 缩小、比例、放大、适合宽度、适合页面。
- PDF/Word 全文搜索与上一处/下一处结果。
- PPT 从当前页或第一页放映。
- Excel 网格/打印预览切换。

文件名仍只出现在全局标题栏和编辑器页签，预览内容区不重复文件名。

缩放范围：

- PDF、Word、PPT、Excel 打印预览：25%–400%。
- Excel 网格：50%–200%。

缩放必须保持当前页或活动单元格位置。工具栏、缩略图模式切换和工作表页签阻止滚轮向自身产生纵向滚动条，但不破坏内容区域的正常滚动。

文档内容区同时支持触控板双指捏合：Chromium/Wails 的 `Ctrl + Wheel` 合成事件和 WebKit `gesturechange` 统一映射到同一缩放动作，使用动画帧合并连续输入并遵守各格式缩放边界。工具栏、导航栏与工作表页签不响应捏合，避免误缩放或出现意外滚动条。

## 5. PDF 与 Word

PDF 和 Word 共用分页查看器：

- 左侧在“缩略图”和“目录”之间切换，可完全收起。
- PDF 目录直接来自 `getOutline()`；Word 目录来自转换后 PDF 的 Outline，不根据字号猜测。
- 无目录时禁用目录模式并回到缩略图。
- 主区连续分页；页面接近可视区时才渲染 Canvas 和 TextLayer，未渲染页保留稳定占位尺寸。
- 当前页只由主滚动视口内的稳定锚点计算，程序化跳转期间暂停滚动回写；目录/缩略图切换后将当前页对应项定位到导航视口中央，不能反向驱动正文重复跳页。
- 每页在 Canvas 绘制前先解析精确页面尺寸，离屏页也使用当前比例的稳定占位；缩放期间保留上一帧 Canvas，下一帧完成后再原位替换，避免页面高度突变、两页间抖动和白屏闪烁。
- TextLayer 恢复文本选择、复制和搜索；后台按页提取文本，搜索覆盖整份文档而不只覆盖已渲染页面。
- 搜索结果支持上一处/下一处并跳转到对应页；当前页随滚动更新。
- 禁止脚本、表单执行、危险链接协议和外部资源。

编辑组宽度不足 720px 时，导航区默认收起并用 `Sheet` 临时打开；宽屏使用 `Resizable` 调节宽度。

## 6. PowerPoint

- 左侧显示 8 张真实幻灯片缩略图，右侧显示当前页。
- 支持上一张、下一张、首页、末页、输入编号跳转、缩放、适合页面和适合宽度。
- 放映可从当前页或第一页开始，使用 Fullscreen API 和黑色背景。
- 键盘支持方向键、PageUp/PageDown、空格、Home、End 和 Escape。
- 放映控制栏在空闲后隐藏，鼠标移动或键盘操作时恢复。
- 窄窗口下缩略图进入临时 `Sheet`。
- 切换幻灯片或缩放时保留上一张已完成的 Canvas，后台完成新帧后再替换，不通过变更 React `key` 强制卸载预览表面。
- 仓库样例使用原生 PowerPoint 导出的 PDF，并校验中文文本与字体资源；未来任意 PPT 转换服务必须报告缺失字体，不能把中文缺失的产物标记为成功。

首版是静态保真放映，不实现 PowerPoint 动画、视频、音频、备注和演示者视图。

## 7. Excel

默认打开 Excel 风格只读网格：

- 局部使用 Excel 绿色语义色，不改变 Aestival 全局主题。
- 显示名称框、只读公式栏、列号、行号、活动单元格和工作表页签。
- 显示单元格值、公式、合并、行列尺寸、字体、填充、边框和对齐。
- 支持键盘移动、点击选择、`Shift + 方向键` 扩展范围、鼠标按下拖动框选连续矩形区域，以及复制为 TSV。
- 网格内容区拥有独立横向/纵向滚动；工具栏、公式栏和工作表页签不出现意外滚动条。工作表页签使用平面标签和仅活动项的绿色底线，不绘制整项边框。
- 图表不在网格内重建；存在图表时提示用户在打印预览中查看。
- 打印预览复用分页文档查看器，保留转换后的图表、分页与版式。

网格源只接收开发期生成的安全 JSON，不在浏览器中执行宏、公式或嵌入对象。

## 8. 状态、安全与无障碍

预览统一使用 `idle / loading / ready / error`：

- 加载中用 `Skeleton` 保持布局。
- 缺失产物、损坏文件、加密 PDF 和解析失败使用 `Alert`，说明原因和可执行下一步。
- PDF Worker 和查看器作为独立懒加载 Chunk，不进入首屏主包。
- 纯图标按钮必须有 `aria-label` 和 `Tooltip`。
- 目录树、缩略图、放映、搜索、工作表页签和网格支持键盘与可见焦点。
- 文档内容可选择；工具栏和应用外壳保持禁选。
- 预览内部不使用 `Card`，页面、幻灯片和网格只以必要边界区分。

## 9. 验收

1. 四个真实样例可从右侧文件树打开，且只进入当前焦点编辑组。
2. 同一文档在两个编辑组的页码、比例和显示模式互不影响。
3. PDF/Word 目录来自真实 Outline，缩略图与页码同步，全文搜索可跳转尚未渲染页面。
4. PPT 的 8 张缩略图、主预览和全屏放映内容一致，键盘导航完整。
5. Excel 两个工作表、样式、合并区域、公式栏和打印预览与样例清单一致。
6. PDF/Word 在目录与缩略图之间切换时保持正文页码不变，当前导航项正确定位，连续观察不发生相邻页面往返抖动。
7. PPT 切换、缩放和放映不出现空白帧，中文内容完整；Excel 可用指针拖动选中连续矩形区域，工作表活动底线与标签边界一致。
8. 四类预览均可在内容区通过触控板捏合缩放；缩放、导航收起、窄窗 Sheet、编辑器拆分和右侧文件面板同时打开时无横向溢出或异常滚动条。
9. TypeScript、Vite production build、文档状态测试、编辑组回归和 `git diff --check` 通过。

## 10. 后续边界

后续真实文件支持需要单独设计 Wails 文档服务，至少负责：

- 受控读取本地二进制与 MIME 探测。
- Office 到 PDF/JSON 的后台转换、缓存、版本与失效策略。
- 加密文档、超大文件、字体缺失和转换失败的错误协议。
- 文件更新后的预览刷新和旧 Object URL 释放。

在该服务落地前，除仓库已登记样例外的 Office 文件不能显示为已成功预览。
