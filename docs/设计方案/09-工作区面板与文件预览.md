# 工作区面板与文件预览

## 1. 面板系统

工作区提供两个承载位置：

- 右侧栏：适合文件树、搜索结果、会话调试等纵向信息。
- 底部面板：适合终端、日志、问题与横向结果。

可用面板类型：

1. 文件
2. 终端
3. 搜索（文件内容搜索）
4. 日志
5. 会话调试

### 1.1 右侧栏

标题行：

- 当前面板图标与名称。
- 更多按钮。
- 移到底部。

面板收起统一由全局标题栏的右侧栏/底部面板按钮负责：面板打开时按钮显示 active 背景，再次点击收起。面板标题行不再放置独立关闭按钮；具体页签仍可通过页签关闭按钮或面板更多菜单关闭。

更多 Dropdown：

- 文件。
- 终端。
- 搜索。
- 日志。
- 会话调试。
- 固定当前面板。
- 重置面板尺寸。

如果没有打开任何面板，使用 `Empty`：

- 标题“选择一个工作区面板”。
- 五个带 Lucide 图标的 Button/Item。
- 可显示对应快捷键。

### 1.2 底部面板

- 首次展开默认“终端 1”。
- 顶部为 Tabs。
- 右侧 `+` 打开五种面板类型。
- 终端允许多个实例；其他类型默认单实例。
- 每个 Tab 可关闭、重命名（适用时）、拖动排序。
- 最后一个 Tab 关闭后保留空状态，不自动关闭整个底栏；再次点击标题栏底栏按钮才收起。

### 1.3 跨位置移动

- 面板 Tab 拖到右侧/底部投放区。
- 右键“移到右侧栏/移到底部”。
- 同一非终端面板不能在两处重复打开；移动保留筛选、滚动和选择状态。
- 终端移动不能重建进程。

## 2. 文件面板

### 2.1 标题与工具栏

- 文件面板标题栏显示“文件”名称，并提供新建文件、刷新。
- 文件树首行不再单独渲染项目名称，避免与面板标题栏重复。
- 全部折叠。
- 更多：隐藏文件、排除规则、跟随活动文件、文件树设置。

无真实项目、当前为固定“任务”时：

- Empty 显示“当前任务没有工作目录”。
- 动作“打开文件夹”“选择最近项目”。
- 不伪造文件树。

### 2.2 文件树

- 使用 `ScrollArea`。
- 文件夹使用 `Collapsible`。
- 行高 24–28px。
- 箭头、Material 文件/文件夹图标、名称、状态装饰。
- 选中、Hover、键盘焦点彼此可区分。
- Git/修改状态作为右侧文字装饰，不改变文件类型图标。

交互：

- 单击文件：临时预览页签。
- 双击文件：固定页签。
- Enter：打开。
- Space：快速预览。
- 左右方向键：折叠/展开或进入层级。
- 支持多选与批量加入会话。
- 右键菜单见 [03-全局交互与右键菜单.md](./03-全局交互与右键菜单.md)。

### 2.3 Material 图标映射

图标资源来自 `frontend/src/assets/icons/material/`，映射以 `docs/文件图标映射.md` 为唯一业务事实来源。

匹配优先级：

1. 精确文件名，如 `package.json`、`go.mod`。
2. 复合后缀，如 `.d.ts`、`.test.tsx`。
3. 普通后缀。
4. 语言 ID。
5. 默认文件图标。

文件夹优先级：

1. 根文件夹精确名。
2. 文件夹精确名。
3. 打开/关闭状态。
4. 默认文件夹。

规则：

- 映射缺失时使用 Material 默认文件/文件夹图标。
- 不用 Lucide 的 `File` 替代已映射类型。
- 不根据扩展名猜测不存在的图标文件。
- 主题切换时保持图标原色；可通过整体饱和度设置降低视觉噪声。
- 图标加载失败记录一次日志，不对每行重复 Toast。

当前仓库尚无映射文档与资源目录，属于实现前置依赖。

## 3. 主内容文件页签

每个编辑组顶部都有自己完整、独立的 Tabs：

- 主编辑组第一项固定为“聊天”，不可关闭、不可拖动；其他编辑组不复制聊天页签。
- 后续为该编辑组实际打开的文件、Diff 或应用编辑页签。
- 不再设置跨编辑组的全局文件页签投影；上、下或左、右编辑组切换页签时互不影响。

文件页签显示：

- Material 图标。
- 文件名。
- 脏状态圆点。
- 只读/锁定状态。
- 关闭按钮（Hover/选中时）。

同名文件在必要时显示父目录。HoverCard 展示完整路径、语言、编码和修改状态。

关闭策略：

- 未修改：直接关闭。
- 已修改：Dialog 提供保存、不保存、取消。
- 文件已被外部修改：Dialog 提供比较、覆盖、重新加载。
- 文件被删除：页签保留并标记，允许另存为或关闭。
- 单击文件树进入当前焦点组的临时预览；双击、编辑或显式固定后转为固定页签。
- 页签可在组内重排，也可拖到其他组；目标组已有同一文件时激活已有页签，移动来源页签直接消失，不制造重复项。

## 4. Monaco 代码编辑器

### 4.1 顶部 Breadcrumb

- 项目 > 文件夹 > 文件 > 当前符号。
- 点击层级打开文件/符号选择 Popover。
- 右侧显示查找、基础提示、格式化、Diff、保存与外部变更状态；语言、编码、换行符和缩进只在底部状态栏展示，避免重复入口。

### 4.2 编辑能力

- 语法高亮。
- 查找/替换。
- 行号、MiniMap、折行设置。
- 格式化。
- 定义、引用、重命名（语言服务可用时）。
- Diagnostics。
- 保存与自动保存。
- 外部变更检测。
- 选区添加到对话、解释、让代理修改。

代理修改文件时：

- 当前编辑器显示外部变更 Marker。
- 未保存冲突时先生成 Diff。
- 用户可接受全部、逐块接受、拒绝。
- 不静默覆盖用户编辑。

### 4.3 编辑器底部状态

使用紧凑状态栏：

- 行/列。
- 空格/Tab。
- 编码。
- 行尾。
- 语言模式。
- Diagnostics 数量。

点击对应项使用 Popover/Command 切换。

### 4.4 编辑组与拆分

- 编辑组使用递归布局树作为唯一结构状态；分割节点记录方向与比例，叶节点引用编辑组。每个编辑组独立保存完整页签顺序、活动页签、临时预览页签和 MRU。
- “向右拆分”或“向下拆分”只复制当前编辑组的活动文件到新组，不复制该组全部页签；聊天页签不可拆分。
- 文件树始终在当前焦点组打开文件。焦点在下方时只更新下方，焦点在上方时只更新上方；任何编辑组的页签切换都不得改写其他组的活动页签。
- 同一文件允许在多个组中打开并共享工作副本，但各组使用独立 Monaco 实例、光标、选区和滚动位置。
- 页签支持组内拖动重排和跨组移动；macOS 按住 Option、其他平台按住 Ctrl 时跨组拖动为复制。跨组移动到已有同一文件的目标组时，激活目标页签并从来源组移除。
- 将页签拖到编辑内容区的上、下、左、右边缘可创建对应方向的新编辑组；边缘拆分热区不得覆盖页签栏，拖到页签栏只执行移动/复制/去重。
- 不设置人为的四组上限；工具栏根据当前组的实际宽高禁用无法保持最小可用尺寸的继续拆分，Resizable 负责比例调整。
- 关闭编辑组只移除该组及其布局分支，不把其中页签合并到相邻组；脏文件仅在最后一个引用关闭时触发保存确认。主编辑组关闭全部文件后回到聊天。
- Markdown 的源码、预览和并排预览是同一个文件页签内的显示模式，不生成第二层文件页签；Diff 是当前组中的独立编辑器输入，但仍使用同一布局状态。

## 5. 常见文件预览

打开方式通过扩展名、MIME 和内容探测共同决定；扩展名冲突时优先安全探测。

| 类型 | 常见后缀 | 预览方式 | 主要动作 |
| --- | --- | --- | --- |
| 代码/纯文本 | 常见源码、txt、log、conf | Monaco | 编辑、查找、编码、加入对话 |
| Markdown | md、mdx | 同页签内源码/预览/并排模式 | 目录、复制、导出 |
| JSON/YAML/TOML/XML | json、yaml、toml、xml | Monaco + 可折叠结构视图 | 格式化、路径复制 |
| CSV/TSV | csv、tsv | Table/DataTable + 文本模式 | 排序、筛选、导出 |
| 图片 | png、jpg、jpeg、gif、webp、bmp、ico | AspectRatio + 缩放画布 | 缩放、复制、下载、加入对话 |
| SVG | svg | 安全预览/源码 Tabs | 缩放、复制源码、下载 |
| PDF | pdf | 分页预览 + 缩略图 | 搜索、页码、下载、加入对话 |
| 音频 | mp3、wav、m4a、ogg、flac | 媒体播放器 | 播放、速度、波形/时长、下载 |
| 视频 | mp4、webm、mov | 媒体播放器 | 播放、画中画、截图、下载 |
| Word | docx | 只读分页预览 | 搜索、复制文本、下载、外部打开 |
| Excel | xlsx、xls | Sheet Tabs + Table | 筛选、复制单元格、外部打开 |
| PowerPoint | pptx | 幻灯片缩略图 + 单页预览 | 翻页、全屏、外部打开 |
| 字体 | ttf、otf、woff、woff2 | 字符样张 | 字号、示例文本、元数据 |
| 压缩包 | zip、tar、gz、7z | 只读文件清单 | 搜索、提取（需审批）、外部打开 |
| SQLite | sqlite、db | 表/Schema 浏览 | 只读查询、分页、外部打开 |
| 可执行/未知二进制 | exe、dll、so、bin 等 | 元数据 + Hex 只读视图 | 哈希、复制路径、外部打开 |

Office 与 PDF 的分页、目录、缩略图、放映、Excel 网格、缩放、编辑器实例状态和样例产物规范统一见 [14-文档预览.md](./14-文档预览.md)。文件树只负责把文档打开到当前焦点编辑组，不在右侧文件面板内部渲染文档。

预览失败时：

- 显示文件名、大小、MIME、修改时间。
- 提供“以文本打开”“Hex 查看”“在系统中打开”“下载/复制”。
- 不把二进制乱码直接塞进 Monaco。

### 5.1 大文件

- 打开前显示大小与性能提示。
- 文本采用分块/只读模式。
- 图片按需解码。
- 表格预览先加载有限行，并显示总量/截断状态。
- 用户可明确选择“仍然完整打开”。

### 5.2 安全预览

- SVG、HTML、Office、PDF 中的脚本和外部资源默认禁用。
- HTML 文件默认以源码打开；“运行预览”需要进入受限预览。
- 外部链接打开前显示目标域名。
- 宏、可执行文件不在预览中运行。

### 5.3 Office/PDF 首版实现边界

- PDF 由浏览器端 PDF.js 解析真实文件；目录必须来自 PDF Outline。
- Word/PPT 使用仓库中已提交的 LibreOffice 转换 PDF，Word 目录来自转换后的 Outline，PPT 标题来自安全清单。
- Excel 默认读取已提交的安全工作簿 JSON，图表和分页通过打印 PDF 查看。
- 相同文件在不同编辑组中的页码、缩放和显示模式按 `editorId` 隔离。
- 未登记预览产物的 Office 文件显示明确错误，不调用外部 Office 服务，也不伪造转换成功。

## 6. 终端面板

### 6.1 Tab 标题

- 终端编号或自定义名称。
- 当前 Shell。
- 运行中进程状态。
- 退出码装饰。

### 6.2 工具栏

- 新建终端。
- 拆分。
- Kill。
- 清空。
- 终端配置。

### 6.3 状态

- 正在启动：Spinner。
- 运行：Marker。
- 已退出：退出码 + 重新启动。
- 权限错误：Alert + 打开设置。
- 项目目录不存在：选择目录。

终端内容有独立滚动与文本选择；全局快捷键不得抢占 Shell 常用快捷键。

## 7. 文件内容搜索面板

这与全局 Command 搜索不同，只搜索项目文件内容。

结构：

- 搜索 Input。
- 替换 Input（可折叠）。
- 大小写、全词、正则 ToggleGroup。
- 包含/排除文件 Field。
- 结果树：文件 > 匹配行。

每个文件显示匹配数量；匹配行展示行号与高亮。点击打开文件并定位。

替换：

- 单项替换。
- 单文件全部替换。
- 全部替换。
- 全部替换前展示影响文件数和 Diff 摘要，使用 AlertDialog。

状态：

- 索引搜索/实时搜索标记。
- 正则错误就地校验。
- 搜索取消。
- 大结果截断和继续加载。

## 8. 日志面板

工具栏：

- 日志源：应用、代理、MCP、任务、应用运行。
- 级别：Trace、Debug、Info、Warn、Error。
- 搜索。
- 自动滚动 Switch。
- 清空视图。
- 导出。

每行：

- 时间。
- 级别 Badge。
- 来源。
- 消息。
- 可展开结构化字段。

清空视图不删除磁盘日志；真正清理日志从设置执行并确认。敏感字段默认脱敏。

## 9. 会话调试

会话调试用于查看每条消息与 AI 交互的过程。

### 9.1 左侧事件列表

按时间展示：

- 用户提交。
- 上下文组装。
- 模型请求。
- 流式事件。
- 工具请求与审批。
- 工具结果。
- 上下文压缩。
- 模型结束/错误。

支持按轮次、模型、工具、状态筛选。

### 9.2 详情 Tabs

| Tab | 内容 |
| --- | --- |
| 概览 | 事件类型、时间、耗时、关联消息 |
| 请求 | 模型、参数、消息结构、工具 Schema |
| 响应 | 流式片段、结束原因、错误 |
| 工具 | 参数、审批、输出、耗时 |
| Token | 估算/实际、缓存、上下文分项 |
| 原始事件 | 可折叠 JSON，只读 |

### 9.3 隐私

- API Key、Authorization、Cookie、环境变量值默认替换。
- 文件路径可按隐私设置缩短。
- “显示敏感字段”需要临时确认，不记住。
- 导出调试包前展示脱敏预览和文件清单。
- 系统隐藏推理不在调试面板展示；仅展示模型提供的思考摘要。

## 10. 面板状态恢复

应用重启后恢复：

- 右侧/底部是否展开。
- 面板类型、顺序与尺寸。
- 文件树展开节点（限制数量）。
- 未关闭文件页签。

不自动恢复：

- 终端历史进程。
- 敏感调试字段显示状态。
- 未确认的权限。
- 已失效的临时预览 URL。

恢复失败时使用一次性 Sonner，并提供“查看详情/重置布局”，不循环弹错。
